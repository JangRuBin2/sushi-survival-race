# 🍣 Sushi Survival Race

> **먹히기 전에 탈출하라!**
> 회전초밥집의 초밥이 되어 손님 젓가락을 피해 달리세요. 3~4라운드가 끝나면 단 하나의 초밥만 바다로 돌아갑니다.

로블록스 멀티플레이 파티 게임 · 엘리미네이션 레이스 · 4~24명 · 한 판 4~5분 · PC / 모바일

> 🚧 **개발 중 (비공개)** — 한 판이 처음부터 우승까지 끝까지 돌아가는 단계예요. 지금은 출시 준비(M4)를 하고 있어요. → [로드맵](#로드맵)

---

## 어떤 게임인가요?

플레이어는 **회전초밥 접시 위의 초밥**이에요. 벨트가 밀어내고, 젓가락이 내려오고, 간장 늪이 발을 붙잡아요.
라운드마다 정해진 인원만 다음 라운드로 넘어가고, 마지막 결승에서 끝까지 버틴 **단 하나의 초밥**만 바다로 탈출해요.

### 왜 다른가요?
- **탈락이 벌이 아니라 볼거리예요.** 떨어지면 젓가락에 집혀 간장에 퐁당 찍힌 뒤 "냠!" 하고 먹혀요. 내가 먹혀도 웃기고, 남이 먹히는 걸 보는 것도 재밌어요.
- **내가 초밥이에요.** 사람이 초밥집을 탈출하는 게임이 아니라, 초밥이 손님을 피해 도망쳐요.
- **짧고 빠른 판.** 3~4라운드, 한 판에 4~5분이에요. 인원이 적으면 라운드도 줄어서 늘어지지 않아요.

## 주요 기능

| | |
|---|---|
| 🏠 **방 시스템** | 방장이 인원(4/8/12/16/24명)과 공개·비공개(4자리 코드)를 정해요. 빠른 참가로 바로 들어갈 수도 있어요. |
| 🔀 **매 판 다른 구성** | 라운드마다 맵과 규칙이 바뀌어요. 첫 판은 레이스, 마지막은 결승이고, 한 판 안에서 같은 맵은 다시 나오지 않아요. |
| 🎬 **연출** | 라운드 소개 플라이스루와 "출발!", 라운드마다 다른 탈락 연출, 우승자가 가게 문을 박차고 바다로 뛰어드는 "탈출 성공!" |
| 🤸 **몸싸움** | 다이브로 몸을 던지고, 앞사람을 잡아서 늦출 수 있어요. 판정은 모두 서버가 해요. |
| 👀 **관전** | 탈락하면 자동으로 남은 사람을 관전해요. 방에는 그대로 남아 다음 판을 함께해요. |
| 📱 **모바일 지원** | 터치 버튼(점프·다이브·잡기)과 작은 화면 배치 |

## 플레이 방법

### 라운드 흐름
```
방 만들기·참가 → 라운드 소개(3초) → 출발! → 통과 / 탈락 → … → 결승 → 우승 연출 → 같은 방으로 복귀
```

| 시작 인원 | 라운드 | 예시 |
|---|---|---|
| 4~8명 | 3라운드 | 8 → 5 → 3 → **1** |
| 9~24명 | 4라운드 | 24 → 16 → 9 → 5 → **1** |

### 조작

| 동작 | PC | 게임패드 | 모바일 |
|---|---|---|---|
| 이동 | WASD | 왼쪽 스틱 | 조이스틱 |
| 점프 | Space | A | 점프 버튼 |
| 다이브 | Shift / E | X | 다이브 버튼 |
| 잡기 (누르고 있기) | 마우스 왼쪽 | R2 | 잡기 버튼 |
| 소리 | 화면 오른쪽 위 🔊 (소리 켬 → 음악 끔 → 모두 끔) | | |

### 맵

| 종류 | 맵 | 규칙 |
|---|---|---|
| 🏃 Race | **회전 벨트** | 거꾸로 미는 컨베이어 벨트. 빨간 원이 뜨면 젓가락이 내려와 집어 가요. |
| 🏃 Race | **간장 늪 & 와사비 산** | 간장 웅덩이는 느려지고, 와사비 패드는 크게 튕겨요. 굴러오는 날치알 공을 조심하세요. |
| 🛡️ Survival | **뜨거운 철판** | 밟은 타일이 달아올라 사라져요. 3층 중 맨 아래로 떨어지면 탈락이에요. |
| 🏆 Final | **회전 꼬치 쇼다운** | 도는 꼬치를 피해 마지막 1명이 남을 때까지 버티세요. |

- **Race**: 결승선에 정해진 인원이 들어오면 끝나요 (최대 90초).
- **Survival**: 정해진 인원만 남거나 시간이 끝날 때까지 버티면 통과예요 (최대 60초).
- **Final**: 마지막 1명이 남는 순간 우승이에요 (최대 90초).

새 맵 **라멘 국물 급류**(Race)와 **셰프의 도마**(Survival)를 만들고 있어요.

## 공정한 수익화

- **능력치를 파는 상품은 없어요 (No Pay-to-Win).** 스킨과 연출은 겉모습만 바꿔요.
- 모두 기본 **계란초밥**으로 시작해요. 다른 초밥 스킨은 로벅스로 사거나, 플레이로 모으는 **밥알 코인**으로 해금할 수 있어요 (출시 준비 단계에서 추가 예정).

## 개발자용

### 기술 스택
- **Roblox Studio + [Rojo](https://rojo.space/)** — 코드는 이 저장소에서 관리하고 Studio와 동기화해요.
- **Luau** (`--!strict`)
- 도구 버전은 [Rokit](https://github.com/rojo-rbx/rokit)으로 고정 (`rokit.toml`): Rojo, StyLua, Selene, [Lune](https://lune-org.github.io/docs)
- 판정(결승선, 탈락, 순위, 잡기, 구매)은 **전부 서버**가 해요. 클라이언트는 입력·UI·연출만 맡아요.
- 맵은 지금 **코드로 생성하는 회색 박스**예요. 그래서 Studio 에셋 없이도 만들고 테스트할 수 있어요.

### 빠르게 시작하기
```bash
rokit install                  # 처음 한 번 (Windows: ~/.rokit/bin을 PATH에)
rojo serve                     # Studio의 Rojo 플러그인으로 Connect → F5
```

### 검증
커밋 전에 네 가지를 모두 통과해야 해요.
```bash
rojo build -o build.rbxl       # 프로젝트 구조 확인
stylua --check src tests       # 포맷
selene src                     # 린트
lune run tests                 # 순수 로직 테스트 (Studio 없이)
```
혼자 테스트하는 방법, 맵 순서를 고정하는 디버그 설정(`Config.DEBUG.forceMapPlan`), 마일스톤별 Studio 확인 목록은 [개발 환경 세팅](docs/DEV-SETUP.md)에 있어요.

### 구조
```
src/server/   매치·라운드·방·탈락·잡기·외형 서비스 (판정)
src/client/   UI, 카메라 중재, 효과음, 연출(fx/), 입력(input/)
src/shared/   설정, 리모트, 그리고 Roblox API 없는 순수 로직 (규칙·판정·연출 계산)
  maps/       맵 모듈 — 공통 인터페이스(MapTypes) 하나로 맵을 추가해요
tests/        Lune으로 돌리는 순수 로직 테스트
docs/         기획서, 스펙, QA 리포트, 변경 기록
```
