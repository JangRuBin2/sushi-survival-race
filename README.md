# 🍣 Sushi Survival Race

> **먹히기 전에 탈출하라!**
> 회전초밥집의 초밥이 되어 손님 젓가락을 피해 달리세요. 3~4라운드가 끝나면 단 하나의 초밥만 바다로 돌아갑니다.

로블록스 멀티플레이 파티 게임 · 엘리미네이션 레이스 · 4~24명 · 한 판 4~5분 · PC / 모바일

> 🚧 **출시 준비 (비공개)** — 출시 준비(M4) 개발까지 끝났고, M5 업데이트(결승 연장전, 맵 15개, 시즌 이벤트, 특별 상품, 코드 보상, 스킨 31종)가 들어갔어요. 맵 아트 다듬기가 진행 중이고, Studio 확인·퍼블리시·비공개 테스트를 준비하고 있어요. → [로드맵](#로드맵)

## 어떤 게임인가요?

플레이어는 **회전초밥 접시 위의 초밥**이에요. 벨트가 밀어내고, 젓가락이 내려오고, 간장 늪이 발을 붙잡아요.
라운드마다 정해진 인원만 다음 라운드로 넘어가고, 마지막 결승에서 끝까지 버틴 **단 하나의 초밥**만 바다로 탈출해요.

### 왜 다른가요?
- **탈락이 벌이 아니라 볼거리예요.** 떨어지면 젓가락에 집혀 간장에 퐁당 찍힌 뒤 "냠!" 하고 먹혀요. 내가 먹혀도 웃기고, 남이 먹히는 걸 보는 것도 재밌어요.
- **내가 초밥이에요.** 사람이 초밥집을 탈출하는 게임이 아니라, 초밥이 손님을 피해 도망쳐요.
- **짧고 빠른 판.** 3~4라운드, 한 판에 4~5분이에요. 인원이 적으면 라운드도 줄어서 늘어지지 않아요.

## 주요 기능

| | |
|---|---|
| 🏠 **방 시스템** | 방장이 인원(4/8/12/16/24명)과 공개·비공개(4자리 코드)를 정해요. 빠른 참가로 바로 들어갈 수도 있어요. |
| 🔀 **매 판 다른 구성** | 라운드마다 맵과 규칙이 바뀌어요. 첫 판은 레이스, 마지막은 결승이고, 한 판 안에서 같은 맵은 다시 나오지 않아요. |
| 🎬 **연출** | 라운드 소개 플라이스루와 "출발!", 라운드마다 다른 탈락 연출, 우승자가 가게 문을 박차고 바다로 뛰어드는 "탈출 성공!" |
| 🤸 **몸싸움** | 다이브로 몸을 던지고, 앞사람을 잡아서 늦출 수 있어요. 판정은 모두 서버가 해요. |
| 👀 **관전** | 탈락하면 자동으로 남은 사람을 관전해요. 방에는 그대로 남아 다음 판을 함께해요. |
| 🍚 **밥알 코인 · 칭호** | 라운드 통과·결승 진출·우승·하루 첫 판마다 코인을 받아요. 우승 횟수에 따라 머리 위에 칭호("탈출 초밥", "전설의 참치", "바다의 왕"), 로비 단상에 최근 우승자가 서요. |
| 🍣 **스킨 탈의실** | 스킨 31종(초밥·타코야키·고양이 초밥·유니콘 롤…)을 3D로 돌려 보고 골라 입어요. 모든 스킨은 크기·판정이 같아요. |
| 🎃 **시즌 이벤트** | 할로윈·크리스마스 기간에 이벤트 재화(🍬/⭐)를 모아 한정 스킨으로 바꿔요. 로비도 시즌 장식으로 바뀌어요. |
| 🎁 **상점 · 🎟 코드** | 스킨 묶음, 탈락·우승 연출 팩(고양이 손님·불꽃놀이), VIP 패스(👑 이름표·금박 스킨). 코드를 넣으면 밥알 코인을 받아요. |
| 💾 **저장** | 코인·승수·스킨·소리 설정이 나갔다 들어와도 남아요. |
| 📱 **모바일 지원** | 화면 크기에 맞춘 UI, 엄지 쪽에 모인 터치 버튼(점프·다이브·잡기), 가로 고정 |

## 플레이 방법

### 라운드 흐름
```
방 만들기·참가 → 라운드 소개(3초) → 출발! → 통과 / 탈락 → … → 결승 → 우승 연출 → 같은 방으로 복귀
```

| 시작 인원 | 라운드 | 예시 |
|---|---|---|
| 4~8명 | 3라운드 | 8 → 5 → 3 → **1** |
| 9~24명 | 4라운드 | 24 → 16 → 9 → 5 → **1** |

| 🛡️ Survival | **튀김 냄비 탈출** | 차오르는 기름을 피해 나선 발판을 타고 위로! 튀는 기름도 조심. |
| 🛡️ Survival | **와르르 나무 블록** | 블록탑의 칸이 하나씩 가라앉으며 기울어요. 가운데가 가장 안전해요. |
| 🛡️ Survival | **고양이 카페 캣타워** | 좁은 선반을 옮겨 다니며 장난감 공과 고양이 발을 피해요. |
| 🏆 Final | **회전 꼬치 쇼다운** | 도는 꼬치를 피해 마지막 1명이 남을 때까지 버티세요. 연장전에는 꼬치가 빨라지고 접시가 바깥부터 무너져요. |
| 🏆 Final | **연어알 폭탄 접시** | 셰프 숟가락이 떨어뜨리는 연어알 폭탄을 피해요. 접시가 바깥부터 깨져 나가요. |
| 🏆 Final | **줄다리기 발판** | 사람이 몰린 쪽으로 기우는 시소 위에서 균형을 잡아요. |
| 🏆 Final | **인형뽑기 기계 속** | 집게가 바닥 칸을 들어 가요. 연장전에는 상자가 기울며 낮은 쪽부터 사라져요. |

- **Race**: 결승선에 정해진 인원이 들어오면 끝나요 (최대 90초).
- **Survival**: 정해진 인원만 남거나 시간이 끝날 때까지 버티면 통과예요 (최대 60초).
- **Final**: 마지막 1명이 남는 순간 우승이에요. 90초가 지나면 **⚡ 연장전** — 20초 동안 발판이 무너져 설 곳이 사라지고, 가장 늦게 떨어진 초밥이 우승해요.

## 공정한 수익화

- **능력치를 파는 상품은 없어요 (No Pay-to-Win).** 스킨은 겉모습만 바꾸고, 뽑기(랜덤 상품)도 없어요.
- 모두 기본 **계란초밥**으로 시작해요. 다른 스킨 25종은 **R$ 29~199**로 바로 사거나, 일반·레어 **15종은 플레이로 모으는 밥알 코인**(300 / 900)으로 해금할 수 있어요. 시즌 한정 스킨 중 2종은 이벤트 재화로 무료 교환이에요.
- 묶음·연출 팩·VIP 패스도 겉모습만 바꿔요(VIP에 코인 배수 없음). 코인을 로벅스로 파는 상품은 없어요.

## 개발자용

### 기술 스택
- **Roblox Studio + [Rojo](https://rojo.space/)** — 코드는 이 저장소에서 관리하고 Studio와 동기화해요.
- **Luau** (`--!strict`)
- 도구 버전은 [Rokit](https://github.com/rojo-rbx/rokit)으로 고정 (`rokit.toml`): Rojo, StyLua, Selene, [Lune](https://lune-org.github.io/docs), luau-lsp
- 판정(결승선, 탈락, 순위, 잡기, 코인, 구매, 이동 감시)은 **전부 서버**가 해요. 클라이언트는 입력·UI·연출만 맡아요.
- 맵은 판정·장식 모두 **코드로 생성**해요. 그래서 Studio 에셋 없이도 만들고 테스트할 수 있어요. 더 꾸민 장식은 Studio에서 만들어 `assets/map-art/`에 넣으면 붙어요.
- 로비와 매치를 한 플레이스에서 돌리거나, 플레이스 id를 넣으면 로비/매치 서버로 나눠 돌려요.

### 빠르게 시작하기
```bash
rokit install                  # 처음 한 번 (Windows: ~/.rokit/bin을 PATH에)
rojo serve                     # Studio의 Rojo 플러그인으로 Connect → F5
```

### 검증
커밋 전에 다섯 단계를 모두 통과해야 해요.
```bash
rojo build -o build.rbxl       # 1. 프로젝트 구조 확인
stylua --check src tests tools # 2. 포맷
selene src                     # 3. 린트
lune run tests                 # 4. 순수 로직 테스트 (Studio 없이, 1736개 — 마지막 줄의 0 failed 확인)
rojo sourcemap default.project.json -o sourcemap.json
luau-lsp analyze --platform roblox --sourcemap sourcemap.json --definitions "@roblox=types/globalTypes.None.d.luau" --flag:LuauSolverV2=true src   # 5. 타입 검사
```
혼자 테스트하는 방법, 디버그 설정(`Config.DEBUG.forceMapPlan` 등), 마일스톤별 Studio 확인 목록, Studio 없이 맵을 PNG로 보는 렌더러(`lune run tools/render-map <맵 id>`)는 [개발 환경 세팅](docs/DEV-SETUP.md)에 있어요.

**테스트 도구 — 관리자 "🛠" 패널**: 관리자(Studio에서는 모두, 실서버는 서버 전용 `src/server/AdminConfig.luau`의 UserId 목록·게임 소유자)에게만 생겨요. 스킨·연출을 사지 않고 입어 보고(저장 안 됨), Studio에서는 바로 시작·맵 순서·코인 같은 테스트 명령도 써요. 권한은 서버가 계정으로만 판단해요(비밀번호 입력 없음).

**코드 보상 목록**은 저장소가 공개라 커밋하지 않아요 — `src/server/CodeList.example.luau`를 `CodeList.luau`(`.gitignore`)로 복사해 적어요.

### 구조
```
src/server/   매치·라운드·방·탈락·잡기·외형·저장·보상·이동 감시·플레이스·상점 서비스 (판정)
src/client/   UI, 카메라 중재, 효과음, 연출(fx/), 입력(input/)
src/shared/   설정, 리모트, 그리고 Roblox API 없는 순수 로직 (규칙·판정·연출·저장·결제 계산)
  maps/       맵 모듈 15개 + 장식 키트(MapKit·조명·파티클·움직임) — 공통 인터페이스(MapTypes) 하나로 맵을 추가해요
tests/        Lune으로 돌리는 순수 로직 테스트
tools/        맵 미리보기 렌더러 (Lune)
types/        타입 검사용 Roblox 정의 파일
assets/       사용자 Studio 장식 (map-art/)
docs/         기획서, 스펙, QA 리포트, 변경 기록, 사용자 할 일
```
