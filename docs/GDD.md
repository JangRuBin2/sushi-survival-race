# Sushi Survival Race — 게임 기획서 (GDD v0.2)

> "먹히기 전에 탈출하라!"
> 회전초밥집의 초밥들이 손님 젓가락을 피해 가게 밖으로 탈출하는 **라운드제 서바이벌 레이스** (로블록스)

### 변경 이력
- **v0.2**: 방 만들기(인원 설정) 추가, 라운드를 맵마다 다른 규칙 + 3~4라운드로 단축, 기본 스킨 계란초밥, 로벅스 결제 스킨 확정
- v0.1: 최초 작성

## 1. 개요

| 항목 | 내용 |
|---|---|
| 플랫폼 | Roblox (PC / 모바일 / 콘솔) |
| 장르 | 멀티플레이 파티 게임, 엘리미네이션 레이스 (폴가이즈류) |
| 인원 | **방장이 방을 만들 때 설정** (4~24명) |
| 한 판 길이 | **약 4~5분** (3~4라운드, 늘어지지 않게) |
| 타깃 | 8~16세 로블록스 유저, 친구랑 같이 하는 캐주얼 유저 |
| 한 줄 소개 | 내가 초밥이 되어 젓가락을 피해 달리고, 마지막 1개만 살아서 바다로 돌아간다 |

### 1.1 차별점
- **Escape the Sushi Restaurant Obby 류**: 사람이 초밥집에서 탈출하는 혼자 하는 오비 → 우리 게임은 **플레이어가 초밥**이에요.
- **Obby Superstar 류**: 라운드제 탈락 레이스지만 테마가 일반적이에요 → 우리 게임은 **"먹히는" 탈락 연출**이 핵심 콘텐츠예요.
- **탈락이 벌이 아니라 볼거리예요.** 먹히는 모습이 웃겨서 탈락해도 기분이 나쁘지 않고, 클립·숏폼으로 공유하기 좋아요.

## 2. 핵심 루프

```
로비(방 만들기/참가, 스킨 상점) → 3~4라운드 → 우승/탈락 연출 → 보상 → 스킨 구매 → 다시 로비
```

- **한 판 안의 재미**: 살아남는 긴장감 + 남이 먹히는 걸 보는 웃음
- **판 사이의 재미**: 새 초밥 스킨을 사서 입고 자랑하기

## 3. 로비와 방 시스템

### 3.1 로비
- 회전초밥집 카운터 모양의 공간. 벨트 위에 **방 목록이 접시처럼** 돌아가요.
- 로비에서 할 수 있는 것: 방 만들기, 방 참가, 빠른 참가, 스킨 상점, 탈의실(스킨 미리보기)

### 3.2 방 만들기 설정

| 설정 | 선택지 | 기본값 |
|---|---|---|
| 최대 인원 | 4 / 8 / 12 / 16 / 24 | 12 |
| 공개 여부 | 공개 / 비공개(4자리 방 코드) | 공개 |
| 방 이름 | 자유 입력 (로블록스 텍스트 필터 적용) | "○○의 초밥집" |

- **시작 조건**: 방장이 시작 버튼을 눌렀을 때 (최소 **4명**), 또는 정원이 다 차면 10초 뒤 자동 시작.
- 방장이 나가면 가장 먼저 들어온 사람이 방장을 이어받아요.
- **빠른 참가**: 자리가 남은 공개 방 중 시작이 가장 임박한 곳으로 바로 들어가요. 없으면 기본 설정(12명)으로 방을 자동으로 만들어요.

### 3.3 라운드 수는 시작 인원으로 자동 결정
| 시작 인원 | 라운드 수 |
|---|---|
| 4~8명 | **3라운드** |
| 9~24명 | **4라운드** |

인원이 적은데 라운드가 많으면 금방 2~3명만 남아서 늘어지기 때문이에요.

## 4. 매치 흐름

1. **방 출발**: 방 인원 전체가 매치 서버로 이동해요.
2. **라운드 소개**: 맵 플라이스루 카메라 + 맵 이름·규칙 한 줄을 3초간 보여줘요.
3. **라운드 진행**: 맵 규칙에 따라 진행해요 (아래 5장). 모든 라운드는 짧은 시간 제한이 있어요.
4. **결과**: 통과자/탈락자 표시 (5초) → 탈락자는 **관전 모드** 또는 로비 복귀를 골라요.
5. **결승 → 우승 연출 → 보상 정산 → 같은 방으로 로비 복귀** (같은 멤버로 바로 한 판 더 가능)

### 4.1 라운드별 통과 비율

| 라운드 수 | R1 | R2 | R3 | R4 |
|---|---|---|---|---|
| 3라운드 | 60% 통과 | 50% 통과 | **결승 1명** | — |
| 4라운드 | 65% 통과 | 55% 통과 | 50% 통과 | **결승 1명** |

- 계산: `통과 = clamp(round(시작 × 비율), 2, 시작 - 1)` — 최소 2명은 결승에 가고, 매 라운드 최소 1명은 꼭 탈락해요.
- 결승 전에 남은 인원이 **2명 이하가 되면 남은 라운드를 건너뛰고 바로 결승**으로 가요.
- 예시 (24명, 4라운드): 24 → 16 → 9 → 5 → **1**
- 예시 (8명, 3라운드): 8 → 5 → 3 → **1**
- 예시 (4명, 3라운드): 4 → 2 → (R2 생략) 결승 → **1**

## 5. 맵과 라운드

**라운드마다 맵이 바뀌고, 맵마다 규칙이 달라요.** 매 판 맵 풀에서 랜덤으로 골라 구성해서 할 때마다 다른 판이 돼요.

### 5.1 라운드 구성 규칙
- 맵은 **Race(레이스) / Survival(생존) / Final(결승)** 세 종류 중 하나예요.
- 마지막 라운드는 항상 **Final** 맵이에요.
- 그 앞 라운드는 Race와 Survival을 섞되, **첫 라운드는 항상 Race** (인원이 많을 때 레이스가 가장 혼잡하고 재밌어요).
- 한 판 안에서 같은 맵은 나오지 않아요.

| 라운드 수 | 구성 |
|---|---|
| 3라운드 | Race → (Race 또는 Survival) → Final |
| 4라운드 | Race → (Race 또는 Survival) → (Race 또는 Survival, 단 Survival 최소 1번) → Final |

### 5.2 맵 목록 (MVP 6개)

#### 🏃 Race 맵 — 결승선에 목표 인원이 들어오면 종료 (최대 90초)

**① 회전 벨트**
- 손님 테이블 사이를 도는 거대한 컨베이어 벨트.
- 벨트가 진행 반대 방향으로 밀어요.
- **젓가락 집기**: 빨간 원 경고 1초 → 젓가락이 내려와 3초간 들어 올렸다 떨어뜨려요 (시간 손해).
- 간장 종지, 접시 더미로 좁아지는 병목 구간.

**② 간장 늪 & 와사비 산**
- 간장 웅덩이: 속도 50% 감소, 점프 불가.
- 와사비 패드: 밟으면 "매워!!" 하며 크게 튕겨요 (잘 쓰면 지름길).
- 굴러오는 날치알 공: 맞으면 넘어져요.

**③ 라멘 국물 급류**
- 라멘 그릇 속 국물 급류를 타고 내려가는 코스.
- 떠다니는 차슈·나루토 위를 밟고 건너고, 회전하는 젓가락 막대를 피해요.

#### 🛡️ Survival 맵 — 목표 인원만 남을 때까지 버티기 (최대 60초)
떨어지면 **아래에서 입 벌리고 기다리는 손님에게 직행 = 탈락**.

**④ 셰프의 도마**
- 공중에 뜬 원형 도마. 칼이 줄 경고 후 내리쳐서 넉백시켜요.
- 10초마다 도마가 기울고, 조각이 하나씩 잘려 나가요. 시간이 갈수록 빨라져요.

**⑤ 뜨거운 철판**
- 철판 타일 위에 서 있으면 타일이 점점 빨갛게 달아오르다가 1.5초 뒤 사라져요.
- 계속 움직여야 살아요. 층이 3개라 떨어져도 아래층에서 기회가 있어요. 맨 아래층에서 떨어지면 탈락.

#### 🏆 Final 맵 — 1명만 우승 (최대 90초)

**⑥ 꼬치 다리 대탈출**
- 가게 문까지 이어지는 공중 꼬치 다리와 회전 접시 발판.
- 떨어지는 장국 그릇, 막판에 내려오는 **셰프의 거대한 손**.
- 떨어지면 탈락 (재시작 없음). 1등으로 문을 통과하면 우승. 시간이 끝나면 가장 멀리 간 플레이어가 우승.

### 5.3 추가 맵 아이디어 (업데이트용)
- 디저트 냉장고 (Race, 얼음 바닥 미끄러짐)
- 튀김 기름 점프 (Survival, 튀는 기름 방울 피하기)
- 연어 왕관 쟁탈전 (Final, 왕관을 들고 30초 버티기)
- 팀 라운드: 접시 쌓기 (Team, 방 인원이 12명 이상일 때만)

## 6. 조작과 캐릭터

| 입력 | PC | 모바일 | 설명 |
|---|---|---|---|
| 이동 | WASD | 조이스틱 | 기본 속도 16 |
| 점프 | Space | 점프 버튼 | |
| 다이브 | Shift / E | 다이브 버튼 | 앞으로 몸을 날림, 1.5초 쿨다운. 착지 후 0.5초 경직 |
| 잡기 | 마우스 좌클릭 | 잡기 버튼 | 앞에 있는 플레이어를 잡아 늦추기 (최대 2초) |

- **캐릭터 몸**: 밥 블록 + 위에 얹은 재료(토핑). 스킨은 토핑·색·액세서리만 바꾸면 되도록 설계해요.
- **넘어짐(래그돌)**: 큰 충격을 받으면 1초 동안 넘어져요.
- **모든 스킨은 히트박스·속도가 똑같아요.** 스킨은 겉모습만 바꿔요.

## 7. 탈락 연출 (핵심 콘텐츠)

탈락 순간 해당 플레이어 카메라가 3초 동안 연출을 보여줘요.

1. **젓가락 픽업**: 젓가락이 집어 올리면 초밥이 버둥거려요.
2. **간장 찍기**: 간장에 "퐁당".
3. **냠!**: 손님 입으로 들어가고 말풍선이 떠요. ("음~ 신선하네!", "계란초밥은 역시 달달해", "와사비 좀 더 주세요")
4. 화면에 **"먹혔다!" 스탬프** + 등수 표시.

- 맵마다 연출이 달라요 (도마·철판에서 떨어짐 → 손님 입으로 낙하, 결승 → 셰프가 잡아감).
- 말풍선 대사는 **내 스킨에 맞춰** 나와요 (연어 스킨이면 "연어는 역시 최고야").

## 8. 우승 연출
- 가게 문을 박차고 나가 부두에서 바다로 다이빙 → 물고기들이 박수.
- 로비로 돌아가면 방 안 단상에 우승자 초밥이 전시돼요.
- 우승 횟수 칭호: 1승 "탈출 초밥", 10승 "전설의 참치", 100승 "바다의 왕".

## 9. 스킨과 수익화 (로벅스)

### 9.1 원칙
- **기본 스킨은 계란초밥(타마고)** — 모든 플레이어가 처음부터 가지고 있어요.
- 스킨은 **로벅스(Robux)로 바로 구매**해요.
- **능력치를 파는 상품은 없어요** (Pay-to-Win 금지). 스킨·연출은 겉모습만 바꿔요.
- **유료 랜덤 뽑기는 하지 않아요.** 원하는 스킨을 골라서 사는 방식이에요. (로블록스 정책상 유료 랜덤 상품은 확률 공개 등 제약이 많고, 어린 유저 대상이라 신뢰도에도 좋아요.)
- 무과금 유저도 꾸준히 할 이유가 있도록 **밥알 코인(플레이 보상)**으로 일반 스킨 일부를 해금할 수 있어요.

### 9.2 스킨 목록 (초안, 가격은 테스트 후 조정)

| 등급 | 스킨 | 가격 |
|---|---|---|
| 기본 | 🥚 **계란초밥** | 무료 (기본 지급) |
| 일반 | 연어, 참치, 새우, 유부, 오이마키 | 49 R$ 또는 500 코인 |
| 레어 | 장어, 성게, 연어알 군함, 문어 | 99 R$ |
| 에픽 | 무지개 롤, 불꽃 연어(토치), 아보카도 캘리포니아롤 | 199 R$ |
| 전설 | 황금 참치 뱃살, 다이아 성게, 용 롤(움직이는 꼬리) | 399 R$ |
| 시즌 한정 | 할로윈 호박 초밥, 크리스마스 산타 새우 등 | 기간 한정 판매 |

### 9.3 그 밖의 상품
| 상품 | 종류 | 가격 (초안) |
|---|---|---|
| 탈락 연출 팩 (고양이 손님, 상어 손님 등) | 개별 구매 | 79~149 R$ |
| 우승 연출 팩 (불꽃놀이, 고래 타고 퇴장 등) | 개별 구매 | 99~199 R$ |
| VIP 패스 (코인 1.5배, 채팅 태그, 로비 VIP 좌석) | 게임 패스 | 249 R$ |
| 스타터 번들 (일반 스킨 3종 + 탈락 연출 1종) | 개별 구매 | 149 R$ |

### 9.4 밥알 코인 (무료 재화)
- 라운드 통과 +10, 결승 진출 +30, 우승 +100, 하루 첫 판 +50.
- 쓰는 곳: 일반 스킨 해금 (각 500 코인).

### 9.5 결제 구현 메모
- 스킨·연출은 **개발자 상품(Developer Product)**으로 판매하고, 산 기록은 DataStore에 저장해요. 스킨이 많아져도 관리하기 쉬워요.
- 영구 혜택(VIP)만 **게임 패스(Game Pass)**로 판매해요.
- `MarketplaceService.ProcessReceipt`에서 **저장에 성공한 다음에만** 구매 완료를 반환해요 (결제했는데 스킨이 안 들어오는 사고 방지).

## 10. UI 목록

- **결과**: 우승자 + 보상 정산 → "한 판 더" 버튼

## 11. 기술 설계 (Roblox)

### 11.1 개발 환경
- **Rojo**로 코드를 파일로 관리 → GitHub에 버전 관리.
- 언어: **Luau** (타입 체크 사용).
- 맵(3D 모델)은 Roblox Studio에서 만들고 `.rbxm`으로 저장해요.

### 11.2 플레이스 구성
| 플레이스 | 역할 |
|---|---|
| **Lobby** (시작 플레이스) | 방 만들기/참가, 상점, 탈의실 |
| **Match** | 실제 레이스. 방마다 전용 서버를 만들어요 (`TeleportService:ReserveServer`) |

- 방 목록은 여러 로비 서버에서 같이 보이도록 **MemoryStoreService**에 저장해요.
- 방이 출발하면 방 인원 전체를 예약 서버로 텔레포트하고, 방 설정(인원, 라운드 수)을 텔레포트 데이터로 넘겨요.
- **MVP에서는** 한 서버 안에서 로비와 매치를 같이 돌려서 빠르게 테스트하고, M4에서 플레이스를 분리해요.

### 11.3 폴더 구조 (예정)
```
sushi-survival-race/
├── default.project.json
├── src/
│   ├── server/
│   │   ├── RoomService.luau        # 방 생성/참가/방장/시작
│   │   ├── MatchService.luau       # 라운드 구성 → 진행 → 결과 상태 머신
│   │   ├── RoundService.luau       # 맵 로드/시작/종료, 통과자 집계
│   │   ├── EliminationService.luau # 탈락 처리, 관전 전환
│   │   ├── ShopService.luau        # 로벅스/코인 구매, ProcessReceipt
│   │   └── DataService.luau        # 보유 스킨·코인·장착 스킨 저장
│   ├── client/
│   │   ├── UIController.luau
│   │   ├── CameraController.luau   # 소개 플라이스루, 탈락 연출, 관전
│   │   ├── MovementController.luau # 다이브, 잡기 입력
│   │   └── SkinController.luau     # 탈의실 미리보기
│   └── shared/
│       ├── Config.luau             # 통과 비율, 시간 제한, 인원 선택지
│       ├── Skins.luau              # 스킨 목록 (id, 이름, 등급, 가격, 상품 ID)
│       ├── Remotes.luau
│       └── maps/                   # 맵별 규칙 모듈 (Race / Survival / Final 공통 인터페이스)
└── docs/
    └── GDD.md
```

### 11.4 매치 상태 머신
```
RoomWaiting → Starting(카운트다운) → [RoundIntro → RoundActive → RoundResults] × 3~4 → Victory → RoomWaiting
```
- **모든 판정은 서버에서 해요** (결승선 통과, 탈락, 순위, 구매). 클라이언트는 입력과 연출만 담당해요.
- 맵 모듈 공통 인터페이스: `kind`("Race" | "Survival" | "Final"), `setup(map)`, `start(players, targetCount)`, `cleanup()`.
- 장애물은 `CollectionService` 태그(`Chopstick`, `Wasabi`, `SoySauce`, `HotTile`)를 파츠에 달면 동작하게 해요.

## 13. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 방이 안 차서 시작을 못 함 | 최소 4명 시작, 빠른 참가로 사람을 모아줌, 정원 다 차면 자동 시작 |
| 결제했는데 스킨이 안 들어옴 | ProcessReceipt에서 저장 성공 후에만 완료 처리, 구매 기록 별도 저장 |
| 물리 충돌·넘어짐이 끊겨 보임 | 이동은 클라이언트 물리, 판정만 서버에서. 래그돌은 클라 연출 |
| 모바일 조작이 어려움 | 버튼 3개(점프/다이브/잡기)로 제한, M2부터 모바일 테스트 |
| 장르 경쟁 게임이 많음 | 썸네일에 "먹히는 초밥"을 전면에, 탈락 연출 클립으로 홍보 |
