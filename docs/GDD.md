# Sushi Survival Race — 게임 기획서 (GDD v0.1)

> "먹히기 전에 탈출하라!"
> 회전초밥집의 초밥들이 손님 젓가락을 피해 가게 밖으로 탈출하는 **라운드제 서바이벌 레이스** (로블록스)

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 플랫폼 | Roblox (PC / 모바일 / 콘솔) |
| 장르 | 멀티플레이 파티 게임, 엘리미네이션 레이스 (폴가이즈류) |
| 인원 | 서버당 최대 24명, 최소 4명이면 시작 |
| 한 판 길이 | 약 6~8분 (4라운드) |
| 타깃 | 8~16세 로블록스 유저, 친구랑 같이 하는 캐주얼 유저 |
| 한 줄 소개 | 내가 초밥이 되어 젓가락을 피해 달리고, 마지막 1개만 살아서 바다로 돌아간다 |

### 1.1 차별점
기존 로블록스 게임들과 비교하면 이래요.
- **Escape the Sushi Restaurant Obby 류**: 사람이 초밥집에서 탈출하는 혼자 하는 오비 → 우리 게임은 **플레이어가 초밥**이에요.
- **Obby Superstar 류**: 라운드제 탈락 레이스지만 테마가 일반적이에요 → 우리 게임은 **"먹히는" 탈락 연출**이 핵심 콘텐츠예요.
- **탈락이 벌이 아니라 볼거리예요.** 먹히는 모습이 웃겨서 탈락해도 기분이 나쁘지 않고, 클립·숏폼으로 공유하기 좋아요.

---

## 2. 핵심 루프

```
로비(대기·스킨 구경) → 라운드 1~4 → 우승/탈락 연출 → 보상(밥알 코인) → 스킨 구매/뽑기 → 다시 로비
```

- **한 판 안의 재미**: 살아남는 긴장감 + 남이 먹히는 걸 보는 웃음
- **판 사이의 재미**: 코인을 모아 새 초밥 스킨을 얻고 자랑하기

---

## 3. 매치 흐름

1. **로비**: 회전초밥집 카운터. 플레이어가 모이면 30초 카운트다운 (최소 4명).
2. **라운드 소개**: 맵 플라이스루 카메라 + 라운드 이름·목표 3초 표시.
3. **라운드 진행**: 레이스는 통과 인원이 다 차면 종료, 생존은 남은 인원이 목표에 도달하면 종료. 모든 라운드에 시간 제한이 있어요.
4. **결과**: 통과자/탈락자 표시 → 탈락자는 **관전 모드**(통과자 시점 전환 가능) 또는 로비 복귀를 골라요.
5. **결승 → 우승 연출 → 보상 정산 → 로비**

### 3.1 라운드별 통과 인원 (24명 기준)

| 라운드 | 시작 | 통과 | 규칙 |
|---|---|---|---|
| 1 | 24 | 16 | 시작 인원의 약 2/3 |
| 2 | 16 | 10 | 약 60% |
| 3 | 10 | 5 | 절반 |
| 4 (결승) | 5 | **1** | 1등만 우승 |

- 인원이 적을 때는 `통과 = max(2, floor(시작 × 비율))`로 계산하고, 결승은 언제나 1명이에요.
- 남은 인원이 2명 이하가 되면 바로 결승으로 넘어가요.

## 4. 라운드 상세

### Round 1. 회전 벨트 (Race)
- **무대**: 손님 테이블 사이를 도는 거대한 컨베이어 벨트.
- **장애물**
  - 벨트가 진행 방향 반대로 천천히 밀어요.
  - **젓가락 집기**: 바닥에 빨간 원 경고가 1초 뜬 뒤 젓가락이 내려와요. 맞으면 탈락이 아니라 **잡혀서 3초 동안 들어 올려졌다가 떨어져요** (1라운드는 시간 손해만).
  - 간장 종지, 접시 더미로 길이 좁아지는 병목 구간.
- **시간 제한**: 120초

### Round 2. 간장 늪 & 와사비 산 (Race)
- **무대**: 거대한 간장 접시 바다와 와사비 언덕.
- **장애물**
  - 간장 웅덩이: 이동 속도 50% 감소, 점프 불가.
  - 와사비 패드: 밟으면 "매워!!" 하며 랜덤 방향으로 크게 튕겨요 (지름길로도 쓸 수 있어요).
  - 굴러오는 날치알 공: 맞으면 넘어져요.
- 바깥으로 떨어지면 체크포인트에서 다시 시작해요 (시간 손해).
- **시간 제한**: 120초

### Round 3. 셰프의 도마 (Survival)
- **무대**: 공중에 떠 있는 원형 도마.
- **규칙**: 도마 밖으로 떨어지면 **아래에서 기다리는 손님 입으로 직행 = 탈락**.
- **위협 (시간이 지날수록 빨라짐)**
  - 칼질: 바닥에 줄 경고 → 칼이 내리쳐서 맞은 플레이어를 넉백해요.
  - 도마 기울이기: 10초마다 한쪽으로 기울어요.
  - 도마 조각이 하나씩 잘려 나가며 면적이 줄어요.
- **종료**: 목표 인원만 남으면 끝, 최대 90초.

### Round 4. 꼬치 다리 대탈출 (Final Race)
- **무대**: 가게 문까지 이어지는 공중 꼬치(꼬챙이) 다리와 회전 접시들.
- **장애물**: 회전하는 접시 발판, 떨어지는 장국 그릇, 막판에 내려오는 **셰프의 거대한 손**.
- 떨어지면 탈락 (결승은 재시작 없음).
- **1등으로 문을 통과한 1명이 우승.** 아무도 못 들어오면 가장 멀리 간 플레이어가 우승.

### 확장용 라운드 아이디어 (MVP 이후)
- **라멘 국물 수영장** (Race, 수영 구간)
- **튀김 기름 점프** (Survival, 기름 방울이 튀는 바닥)
- **디저트 냉장고** (Race, 얼음 바닥 미끄러짐)
- **팀 라운드: 접시 쌓기** (Team, 팀별로 접시 모으기)

## 5. 조작과 캐릭터

| 입력 | PC | 모바일 | 설명 |
|---|---|---|---|
| 이동 | WASD | 조이스틱 | 기본 속도 16 |
| 점프 | Space | 점프 버튼 | |
| 다이브 | Shift / E | 다이브 버튼 | 앞으로 몸을 날림, 1.5초 쿨다운. 착지 후 0.5초 경직 |
| 잡기 | 마우스 좌클릭 | 잡기 버튼 | 앞에 있는 플레이어를 잡아 늦추기 (최대 2초) |

- **캐릭터 몸**: 밥 블록 + 위에 얹은 재료(토핑). 스킨은 토핑과 색만 바꾸면 되도록 설계해요.
- **넘어짐(래그돌)**: 큰 충격을 받으면 1초 동안 넘어져요. 이 우스꽝스러운 모습이 게임의 맛이에요.

---

## 6. 탈락 연출 (핵심 콘텐츠)

탈락 순간 해당 플레이어 카메라가 3초 동안 연출을 보여줘요.

1. **젓가락 픽업**: 젓가락이 집어 올리면 초밥이 버둥거려요.
2. **간장 찍기**: 간장에 "퐁당".
3. **냠!**: 손님 입으로 들어가고, 말풍선이 떠요. ("음~ 신선하네!", "연어는 역시 최고야", "와사비 좀 더 주세요")
4. 화면에 **"먹혔다!" 스탬프** + 등수 표시.

- 연출 종류는 라운드별로 달라요 (도마에서 떨어짐 → 손님 입으로 낙하, 결승 → 셰프가 잡아감).
- 나중에 **탈락 연출 스킨**(예: 고양이 손님이 먹음)을 판매할 수 있어요.

## 7. 우승 연출
- 가게 문을 박차고 나가 부두에서 바다로 다이빙 → 물고기들이 박수.
- 로비 단상에 우승자 초밥이 다음 판 시작 전까지 전시돼요.
- 우승 횟수에 따라 머리 위 **왕관 칭호**: 1승 "탈출 초밥", 10승 "전설의 참치", 100승 "바다의 왕".

## 8. 성장과 수익화

### 8.1 재화
- **밥알 코인 (무료)**: 라운드 통과 +10, 결승 진출 +30, 우승 +100, 일일 첫 판 +50.
- **로벅스 (유료)**: 게임 패스와 프리미엄 스킨.

### 8.2 스킨 (예시)
| 등급 | 예시 | 획득 |
|---|---|---|
| 일반 | 연어, 참치, 새우, 계란, 유부, 오이마키 | 기본 지급 / 코인 |
| 레어 | 장어, 성게, 연어알 군함 | 코인 |
| 에픽 | 무지개 롤, 불꽃 연어(토치) | 코인 뽑기 / 로벅스 |
| 전설 | 황금 참치 뱃살, 다이아 성게 | 로벅스 / 시즌 보상 |

### 8.3 게임 패스 (공정성 유지가 원칙: **능력치를 파는 상품은 없어요**)
- VIP: 코인 1.5배 + 전용 채팅 태그
- 탈락 연출 팩
- 우승 연출 팩 (불꽃놀이, 고래가 태워감 등)

## 10. 기술 설계 (Roblox)

### 10.1 개발 환경
- **Rojo**로 코드를 파일로 관리 → GitHub에 버전 관리.
- 언어: **Luau** (타입 체크 사용).
- 맵(3D 모델)은 Roblox Studio에서 만들고 `.rbxm`으로 저장해요.

### 10.2 폴더 구조 (예정)
```
sushi-survival-race/
├── default.project.json        # Rojo 프로젝트 설정
├── src/
│   ├── server/                 # ServerScriptService
│   │   ├── MatchService.luau       # 로비 → 라운드 → 결과 상태 머신
│   │   ├── RoundService.luau       # 라운드 로드/시작/종료, 통과자 집계
│   │   ├── EliminationService.luau # 탈락 처리, 관전 전환
│   │   └── DataService.luau        # 코인/스킨 저장 (DataStore)
│   ├── client/                 # StarterPlayerScripts
│   │   ├── UIController.luau
│   │   ├── CameraController.luau   # 소개 플라이스루, 탈락 연출, 관전
│   │   └── MovementController.luau # 다이브, 잡기 입력
│   └── shared/                 # ReplicatedStorage
│       ├── Config.luau             # 라운드 순서, 통과 비율, 시간 제한
│       ├── Remotes.luau            # RemoteEvent 정의
│       └── rounds/                 # 라운드별 모듈 (Race / Survival 공통 인터페이스)
└── docs/
    └── GDD.md
```

### 10.3 매치 상태 머신
```
Waiting → Intermission(30s) → RoundIntro → RoundActive → RoundResults
   ↑                                         │
   └──── Victory ← (남은 인원 1명 or 결승 종료) ┘
```

- **모든 판정은 서버에서 해요** (결승선 통과, 탈락, 순위). 클라이언트는 입력과 연출만 담당해서 핵·치트를 막아요.
- 라운드 모듈 공통 인터페이스: `setup(map)`, `start(players)`, `onPlayerFinished`, `onPlayerEliminated`, `cleanup()`.
- 장애물은 `CollectionService` 태그(`Chopstick`, `Wasabi`, `SoySauce`)로 붙여서, 맵을 만들 때 파츠에 태그만 달면 동작하게 해요.

## 11. 개발 마일스톤

| 단계 | 목표 | 완료 기준 |
|---|---|---|
| **M0. 세팅** | Rojo + GitHub 레포 + 빈 플레이스 | Studio에서 코드 동기화 확인 |
| **M1. 뼈대** | 매치 상태 머신, 라운드 1개(회색 박스 맵), 결승선 판정 | 4명이 들어와서 1라운드 → 통과자 집계까지 |
| **M2. 플레이 가능 MVP** | 4라운드 전부(회색 박스), 탈락 처리, 관전, 우승 | 한 판이 처음부터 끝까지 돌아감 |
| **M3. 맛 내기** | 초밥 캐릭터, 탈락·우승 연출, 다이브/잡기, 사운드 | 친구 테스트에서 "웃기다" 반응 |
| **M4. 출시 준비** | 맵 아트, 코인·스킨 상점, DataStore 저장, 모바일 UI | 비공개 테스트 → 공개 |
| **M5. 운영** | 새 라운드 추가, 시즌 스킨, 이벤트 | 2주마다 업데이트 |

## 12. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 서버 인원이 적으면 재미가 없음 | 최소 4명 시작, 인원 비율로 통과 수 계산, 나중에 봇 초밥 추가 검토 |
| 물리 충돌·넘어짐이 서버-클라 간 끊겨 보임 | 이동은 클라이언트 물리(기본 소유권), 판정만 서버에서. 래그돌은 클라 연출로 처리 |
| 모바일에서 조작이 어려움 | 버튼 3개(점프/다이브/잡기)로 제한, 모바일 테스트를 M2부터 |
| 장르 경쟁 게임이 많음 | 썸네일·아이콘에서 "먹히는 초밥"을 전면에. 탈락 연출 클립으로 홍보 |
