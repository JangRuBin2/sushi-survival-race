## 1. 가격·등급 — 새 조사 없이 확정값을 따름
- 전설 = **R$ 199**, 코인 해금 없음 — 사용자 확정 A안(2026-10-08, GDD 9.2). 근거는 [`REFERENCE-roblox-monetization.md`](REFERENCE-roblox-monetization.md) 3·7절(반사적 구매 구간에서 등급마다 약 2배). 이미 있는 전설 5종(황금 참치 뱃살·다이아 성게·용 롤·크라운 참치·유니콘 롤)과 같은 값.
- 전설 등급 효과 2개·외곽 ±25%는 m5-21 규칙(GDD 9.2 "효과 예산"). 근거 사례는 Pet Simulator 99 오라·Bee Swarm Simulator 등급별 변경 항목 수 — `docs/proposals/skin-quality-and-variety.md` §0.
- 전설의 "값어치"를 정할 때 참고: 장르 인기작은 비싼 겉모습일수록 **움직임**(용 롤 꼬리처럼)을 차별점으로 쓴다(같은 제안서 §0·§4). 이 스킨의 차별점도 효과 개수가 아니라 팔딱 움직임에 둔다(사용자 요청).

## 2. 물고기 움직임 수치의 근거

| 자료 | 내용 | 표기 |
|---|---|---|
| 넙치 정상 유영 | 꼬리 1.00~2.67 Hz | [검색] [Sample records for tail beat frequency (science.gov)](https://www.science.gov/topicpages/t/tail+beat+frequency) |
| 메기 | 지속 유영 2~4.5 Hz, 빠른 유영에서 약 10 Hz까지 | [검색] 같은 모음 |
| 날치 수면 꼬리치기 | 13.5 Hz (물 위에서 꼬리로 물을 치는 동작) | [검색] [APS 2024 Flying fish taxiing](https://meetings-archive.aps.org/mar/2024/s27/13) |
| 물 밖 퍼덕임 실측 | **확인 못 함** (육상 퍼덕임 연구를 찾지 못함) | — |

우리 판단 (추정)
- **느린 꼬리 살랑임 1~1.5 Hz**(정상 유영 범위) = 서 있을 때 "살아 있음".
- **팔딱 순간 5~7 Hz**(빠른 유영~버스트) = 놀란 물고기. 실제 퍼덕임은 더 빠를 수 있지만 **휴대폰 30fps에서 8 Hz를 넘으면 프레임마다 다른 쪽에 찍혀 떨림처럼 보인다**(1주기에 4프레임 이하) → 상한 7 Hz.
- 달릴 때는 걸음 위상에 묶어 걸음과 엇박이 나지 않게(m5-27 팔 흔들기와 같은 방식).
- 각도: 팔 흔들기 35°(m5-27 `ARM_SWING`)가 게임 화면에서 잘 읽힌 기준. 꼬리는 몸보다 작아 같은 각도면 덜 보이므로 팔딱 때 최대 40°, 평소는 그보다 훨씬 작게.

## 3. 비주얼 — "신선한 고등어"를 읽히게 하는 요소 (사용자 시트 `docs/고등어 초밥 캐릭터 시트.png` 기준)
- 등: 청회색 + 짙은 남색 **물결 줄무늬**(고등어를 다른 생선과 구분하는 첫 신호).
- 배: 은백색, 금속 느낌(옆에서 빛을 받으면 반짝).
- 윤기: 등 전체가 젖은 듯 반짝 — 하이라이트 띠(밝은 얇은 파츠)나 반사 재질.
- 큰 눈(크림색 테두리 + 검은 눈동자 + 흰 하이라이트), 살짝 벌린 입.
- 갈라진 꼬리지느러미(V자), 가슴·등지느러미(반투명 느낌 청회색).
- 김 띠가 고등어 뒤쪽 1/3쯤을 비스듬히 감아 밥까지 내려감.
- "팔딱!"·"첨벙!" 물방울 — 파란 물방울 몇 개.
