# 참고 자료 — 파티 로얄 게임 (Fall Guys, Bro Falls)

> **참고용이며 결정이 아니다.** 실제 기획은 `docs/GDD.md`와 `docs/specs/`가 정한다.
> M3(맛 내기) 스펙을 쓰려고 2026-10-08 웹 검색으로 모았다. 공개 기사·가이드에서 확인한 사실과,
> 우리 게임에 옮길 때의 해석("→ 우리 게임")을 나눠 적었다. 수치는 공개 자료에 없어서 우리 기본값은 스펙에서 정했다.

## 0. 조사 대상
| 게임 | 무엇인가 | 확인한 것 |
|---|---|---|
| **Fall Guys** (Mediatonic → Epic) | 원조 파티 로얄. 젤리빈 캐릭터, 라운드마다 탈락 | 위키피디아, 공략 기사 |
| **Bro Falls: Ultimate Showdown** (Boros Bros, 2021) | Fall Guys풍 무료 파티 로얄. **캐릭터가 음식**(파인애플, 계란 프라이, 스테이크, 치즈 등). PC(Steam)·Switch | 게임 소개 기사 |

- 지시에는 "브로폴즈(로블록스 게임으로 보임)"라고 되어 있었지만, 검색으로는 **로블록스판 "Bro Falls"를 찾지 못했다.** 찾은 것은 Steam·Switch의 *Bro Falls: Ultimate Showdown*이다. 음식 캐릭터 파티 로얄이라 우리 게임과 테마가 가장 가깝다. 사용자가 다른 로블록스 게임을 뜻했다면 이름을 알려 주면 보강한다.

## 1. 라운드 구성 · 맵 로테이션
- Fall Guys: 한 판은 보통 **4~5개 미니게임**. 라운드는 **랜덤으로 뽑고, 같은 라운드도 변형(variation)이 랜덤**이다. 종류는 Course(레이스), Survival, Points, Team, Logic, Final 등. 마지막 Final의 승자가 우승.
- Fall Guys는 "Main Show"(전체 라운드 풀) 외에 **테마별로 라운드를 묶은 기간 한정 쇼**를 주 단위로 돌린다. 연속으로 팀 게임이 나오지 않게 한 패치도 있었다.
- Bro Falls: 최대 60명 중 59명이 코스를 달리고, **무작위로 고른 1명(브로콜리)이 함정을 원격으로 작동**시킨다. 마지막 10명이 결승에 가고, 결승에는 브로콜리도 직접 들어온다.
- → 우리 게임: 지금 규칙(첫 라운드 Race, 마지막 Final, 같은 맵 중복 없음, 4라운드면 Survival 1번)이 Fall Guys와 같은 방향이다. **맵 안의 랜덤 변형**(장애물 배치·패턴을 시드로 조금씩 바꾸기)은 M4 맵 아트 때 검토할 만하다. "탈락자가 함정을 조작" 같은 비대칭 요소는 M5 이후 아이디어 (제안서 대상, 결정 아님).

## 2. 라운드 소개 연출
- Fall Guys: 라운드 로딩 화면에 모드 설명이 나오고, **코스 위를 훑는 플라이오버 카메라** 동안 같은 설명이 다시 나온다(배경 위에서 더 잘 읽힌다는 평). **카운트다운과 결과("Qualified!"/"Eliminated")는 크고 두꺼운 장난스러운 글씨**로 띄운다. 라운드 소개 중 연결 안정성을 고친 패치가 있을 만큼 소개 구간은 네트워크 부담이 있는 구간이다.
- → 우리 게임 (m3-04): 3초 소개 동안 맵을 훑는 카메라 + 이름·규칙 한 줄, 끝에 큰 글씨 "출발!". 소개 구간에서 서버는 이미 맵을 지어 두므로(M2), 클라이언트는 **맵이 생길 때까지 기다렸다가** 카메라를 시작하고, 늦으면 건너뛴다.

## 3. 탈락 · 우승 연출
- Fall Guys: 래그돌 물리를 **일부러 웃기게** 넣었다. 탈락하면 남은 사람을 관전한다. 우승자는 왕관을 받는다.
- Bro Falls: 이야기 자체가 "인기 없는 브로콜리가 잘 팔리는 음식들을 납치해 대결시킨다"는 **음식 테마 개그**다.
- → 우리 게임 (m3-03, m3-05): GDD 7·8장의 "먹히는" 연출이 차별점이다. Fall Guys처럼 **크고 두꺼운 글씨의 스탬프**("먹혔다!"), 짧고 과장된 동작, 래그돌스러운 버둥거림이 핵심. 남이 먹히는 걸 보는 웃음이 목표라서 **탈락 연출은 주변 사람 화면에도 보이게** 한다(카메라는 본인만).

## 4. 다이브 · 잡기 조작감
- Fall Guys 다이브: 앞으로 몸을 던진다. **투사체 피하기, 점프 체공 늘리기, 결승선 직전 한 번 더 내밀기**에 쓴다. 다이브 뒤 **바닥에서 잠깐 못 움직이는 회복 시간**이 있어서 **연타하면 그냥 달리는 것보다 느리다**. 다이브 중 맞으면 더 오래 넘어진다.
- Fall Guys 잡기: 버튼을 **누르고 있는 동안** 잡고, 그동안 상대를 당기거나 밀 수 있다. **잡는 사람도 조금 느려진다.** 오래 잡을수록 진동이 세지고, 최대가 되면 상대가 들고 있던 것을 놓친다. 상대가 점프하는 순간 잡아서 구덩이에 떨어뜨리는 플레이가 가능하다(악용 여지). 패치로 장애물을 잡고 기어오르는 것, 잡은/잡힌 상태에서 바람에 버티던 버그를 고쳤다.
- 부딪히는 각도·속도에 따라 느려지거나 멈추거나 넘어진다(stumble).
- Fall Guys 기본 키: PC는 **다이브 = 왼쪽 Ctrl, 잡기 = Shift**, 콘솔은 잡기가 오른쪽 큰 숄더 버튼(R2/RT). 우리 GDD 6은 다이브 = Shift/E, 잡기 = 좌클릭이라 PC 키는 다르다(로블록스는 좌클릭 = 행동이 익숙). 게임패드는 다이브 X, 잡기 R2로 맞췄다(m3-06, m3-07).
- → 우리 게임 (m3-06, m3-07): GDD 값(다이브 쿨다운 1.5초, 착지 경직 0.5초, 잡기 최대 2초)이 Fall Guys 감각과 맞다. 잡기는 **"늦추기만"** 하고 끌고 가기·밀기는 하지 않는다(어린 유저 대상, 악용 줄이기). **잡는 사람도 느려지게** 해서 잡기만 계속하는 플레이가 손해가 되게 한다. 장애물·벽은 잡을 수 없다(플레이어만).

## 5. 사운드 · 카메라
- Fall Guys: 밝고 장난스러운 음악, 큰 글씨 UI, 카메라는 3인칭 추적. 공개 자료에 구체적인 사운드 설계 문서는 찾지 못했다.
- → 우리 게임 (m3-08): 짧고 과장된 효과음(냠!, 퐁당, 뿅, 매워!!)을 이벤트마다 하나씩, 단계별 배경음(대기·라운드·결승·우승). 볼륨은 효과음보다 배경음을 낮게.

## 6. 로블록스로 옮길 때 메모 (구현 참고, 결정 아님)
- 캐릭터 이동은 클라이언트 물리라 다이브 자세(루트 기울기)는 자동으로 복제된다. `Humanoid.PlatformStand`는 우리 게임에서 "넘어짐" 신호라 다이브에 쓰지 않는다(m3-06).
- 서버 `WalkSpeed`는 간장·젓가락·이동 잠금이 이미 쓰고 있어서, 잡기 감속은 각자 클라이언트의 이동 입력 배수(`Humanoid:Move`)로 했다(m3-07).
- 2022년 오디오 비공개 정책 뒤로 남이 올린 오디오 id는 재생되지 않을 수 있다. 효과음은 클라이언트 기본 소리(`rbxasset://sounds/...`)로 먼저 채우고, 음악은 사용자가 Creator Store에서 고른다(m3-08).
- Lune 테스트 환경에는 `Vector3`/`CFrame`이 없어서 연출·조작 순수 로직은 숫자 표로 쓴다(m3-04 결정 기록).

## 7. M3 기본값 색인 (2026-10-08, 사용자 지시로 기본값으로 진행)
| 항목 | 기본값 | 스펙 |
|---|---|---|
| 우승 단계 길이 | 10초 (연출 6 + 순위표 4) | m3-01, m3-05 |
| 아바타 | 로블록스 아바타를 불러오지 않고 모두 계란초밥, 히트박스는 기본 휴머노이드 그대로 | m3-01, m3-02 |
| 탈락 연출 | 방 전원이 월드에서 봄, 카메라·스탬프는 본인만. Race·리셋 = 젓가락, Survival 낙하 = 손님 입, 결승 = 셰프 손. 동시 6개 | m3-03 |
| 관전자 | 보던 사람이 떨어지면 3초 더 비춤 | m3-01 |
| 라운드 소개 | 3초(비행 2.4 + 복귀 0.6), 뛰는 사람만, "출발!" 0.8초 | m3-04 |
| 우승 연출 | 문 → 부두 → 다이빙 → 물고기 박수, 방 전원, 로컬 장면 | m3-05 |
| 다이브 | 쿨다운 1.5, 경직 0.5, 수평 40, 위 16, 로비에서도 가능, 서버 검증 없음 | m3-06 |
| 잡기 | 거리 5, 60도, 최대 2초, 대상 ×0.5, 잡는 사람 ×0.7, 쿨다운 1.5, 면역 1, 레이서끼리만, 늦추기만 | m3-07 |
| 사운드 | 기본 소리로 효과음, 음악은 비워 둠, 효과음 0.7 / 음악 0.3, 3단계 음소거 | m3-08 |
| 장애물 소리 | 서버가 파트에 Sound 재생, 같은 소리 0.2초 간격 | m3-09 |

- 로블록스판 "Bro Falls"는 2026-10-08 두 번째 검색("Roblox Bro Falls", "브로폴즈 로블록스")에서도 찾지 못했다. Steam·Switch의 *Bro Falls: Ultimate Showdown*만 확인된다.
