## 렌더 비평 (회차별, `--quality fast` 스튜디오 조명 → 최종 high)
### 1회차 — 첫 모양
- 참치: 진빨강 돔 + 결 4줄로 "참치" 바로 읽힘. 다만 결이 너무 가늘어(0.08~0.13) 뒤 카메라 거리에서는 거의 안 보일 것 같음.
- 새우: 흰 돔 + 주황 줄은 좋음. 꼬리 쐐기 2장이 작고 앞에서 "작은 빨간 리본"처럼 보임. 가장자리(베개)가 돔과 같은 흰색이라 밋밋.
- 계란: 노란 상자(세로 모서리만 둥근 roundedPrism)가 **각진 도시락 뚜껑**처럼 보임 — 위·아래 모서리가 날카로워 콘셉트의 폭신함과 다름. 겹 줄(0.06)이 거의 안 보임. 그리고 겹 줄 양 끝이 덩어리 옆면과 같은 평면 → z-fighting 4건(LayoutCheck가 잡음) → 겹 줄 길이 −0.06.
- 연어알: 검은 그릇 + 주황 알 11알로 군함이 바로 읽힘. 다만 위에서 보면 주황뿐이라 단조로움 (기존 ikura 스킨의 초록 잎 같은 포인트가 없음).
- 고침: 참치 결 폭 ×1.5, 새우 꼬리 3장(가운데 + 양옆 28° 기울임)·가장자리 주황빛(`SHRIMP_RIM`, `dome`에 rimColor 인자), 계란을 모든 모서리 둥근 **베개(pillow)**로 + 김 띠를 앞뒤 둥근 모서리를 감싸는 같은 축 원기둥 조각으로, 연어알에 오이 조각(축 기울인 원판) 하나.
### 2회차
- 새우: 꼬리 부채가 뒤에서 "V자 + 가운데"로 또렷. 주황빛 가장자리 덕에 3/4에서 익힌 새우 느낌. 
- 계란: 둥근 베개가 되어 폭신해짐. 그런데 두께 0.95라 연어 돔(꼭대기 1.97)보다 낮고(1.78) 납작한 "노란 방석" — 다른 콘셉트 스킨 옆에 서면 키가 작아 보임. 겹 줄 색(232,156,36)이 노랑과 대비가 약해 뒤에서 안 보임.
- 연어알: 오이가 뒤 왼쪽에서 초록 점으로 보여 포인트가 생김. OK.
- 참치: 결이 보이기 시작. 뒤(3/4)에서는 아직 연어와 같은 "줄무늬 돔" 문법이라 색 말고 구분점이 약함 → 김 띠가 없는 것이 구분점이 되는지 게임 카메라로 확인하기로.
- 고침: 계란 두께 0.95 → 1.1, 중심 1.3 → 1.38(꼭대기 1.93, 연어와 비슷), 겹 줄 더 진하게(196,120,30)·두께 0.07 → 0.1. 렌더 도구에 `--sample <스킨 id>` 추가(게임 카메라·휴대폰·표정·비교 그림을 스킨별로).
### 3회차 — 게임 카메라·휴대폰 (다른 콘셉트 스킨 2명과 같이)
- 뒤 카메라(12.5 studs): 참치 = 빨간 돔에 흰 줄, 김 띠가 없어 옆의 연어(가운데 검은 띠)와 바로 구분됨. 새우 = 흰 몸 + 빨간 꼬리 실루엣이 가장 잘 읽힘. 계란 = 노랑 + 세로 김 띠, 기존 계란초밥 스킨 문법과 같아 바로 읽힘. 연어알 = 검은 상자 + 주황 꼭대기.
- 휴대폰 뒤(480×270): 참치 결이 1~2픽셀이라 거의 안 보이고 "빨간 돔"으로만 읽힘 — 색만으로도 구분은 되지만 결이 좀 더 보였으면. 새우 꼬리는 휴대폰에서도 잘 보이지만 조금 작음.
- 휴대폰 앞(로비 조명): 세 명의 얼굴·표정(신남 ^ ^, 당황 땀)이 보임. 연어알의 그릇 앞면이 밥 속이라 얼굴이 가려지지 않음(테스트로도 고정).
- 표정 4종(새우): 모든 표정이 연어와 같은 자리, 토핑이 이마를 가리지 않음.
- 비교(지금 ikura ↔ concept-ikura): 같은 "김 그릇 + 연어알" 문법인데 콘셉트 쪽이 넓고 낮아 귀여움. 알 개수는 12 → 11로 비슷.
- 고침: 참치 결 폭 한 번 더 +20%(0.17~0.24), 새우 꼬리 쐐기 크기 1.0×0.7 → 1.15×0.78, 연어알 지름 0.64 → 0.68(알끼리 살짝 겹쳐 더 수북하게).
### 4회차 — 최종 (high, 스튜디오·로비)
- 휴대폰 뒤: 참치 결이 줄로 보이기 시작, 새우 꼬리가 확실한 실루엣. 
- 36칸 줄 세우기: 콘셉트 5종이 기존 31종(세로로 긴 큰 눈 몸)과 확실히 다른 "넓고 낮은 + 팔다리" 스타일로 한 묶음으로 보이고, 5종끼리는 색·실루엣(돔/돔+꼬리/베개/그릇)이 모두 달라요.
- 남은 아쉬움: 참치는 결국 "연어와 같은 돔, 색만 다름"에 가까움 — 더 나누려면 사선 결(메시 필요) 또는 대뱃살 마블(작은 공·원판 여러 개, 파츠 +4~6)이 필요해요. 지금은 파츠를 아끼는 쪽(기본 41)으로 뒀어요.
