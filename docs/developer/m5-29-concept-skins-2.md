#### 결정 (개발)
- **우니·장어 모양은 사용자 시트를 따랐어요** (스펙 표의 "장어 = 연어 문법 돔 + 구운 자국", "성게 = 연어알 그릇 재사용"과 다름): 두 스킨 모두 **몸 위쪽을 김 띠가 한 바퀴** 두르고(y 0.32~, 얼굴·팔은 띠 아래라 안 가려요), 장어는 그 위에 넓게 늘어진 진갈색 윤기(Glass) 판 + 가운데 세로 김 띠(위 → 앞 띠, 위 → 등 아래), 성게는 띠가 밥보다 높이 솟은 그릇(1.45) 위에 주황 덩어리 4줄 + 초록 잎 둘.
  - 장어 **구운 자국은 뺐어요**(시트에 없음). 시트의 **참깨**는 파츠 상한 47 때문에 뺐어요(넣으면 당황 표정 49).
  - 성게 **초록 잎**은 시트에 있어서 넣었어요(스펙 개발 메모의 "오이 없음"은 연어알과 헷갈리지 않게 하려는 것 — 잎은 맨 위 가운데의 작은 V자라 연어알 구석의 오이 원판과 다르고, 그릇 모양·알 없음으로 이미 구분돼요).
  - 성게 그릇은 연어알과 달리 **등·옆 아래가 밥**이에요(시트대로). 연어알은 등·옆 전체가 김이라 뒤에서 보면 더 잘 구분돼요.
- **유부 받침도 유부 색**(스펙 "받침 색은 그대로"에서 바꿈 — 스펙이 허용한 개발 결정): 밥과 받침이 0.01 겹쳐 옆면이 같은 평면이라 색이 다르면 z-fighting 검사에 걸려요. 다리가 흰색이라 발과 몸은 그대로 구분돼요.
- **유부 입 덮개(MouthCover)도 유부 색**: 입 원판 윗변을 가리는 얇은 덮개가 밥 색이라 유부 위에 흰 네모로 보였어요. 크기·위치는 그대로, 색·재질만 몸을 따라가요(테스트 고정). 다른 스킨은 그대로(스냅숏 같음).

#### 렌더 비평 (studio 조명, 매 회차 turntable·mobile-back 확인)
1. **1회차** (이전 세션 첫 모양 → 시트 반영 첫 판) — 우니: 노란 소시지 4개처럼 보임, 시트는 주황의 울퉁불퉁한 볼록 더미. 장어: Glass 등성이 원기둥 끝이 앞에서 "귀"처럼 솟고 색이 적갈색, 세로 김 띠 윗부분이 판 위로 기둥처럼 솟음(옆에서 검은 막대).
2. **2회차** — 장어: 등성이를 빼고 판 전체를 윤기 판으로, 김 띠는 판 모서리 원기둥으로 휘게 → 구조는 시트와 비슷해졌지만 빨간 주황이라 연어와 헷갈림. 우니: 여전히 노랗고 길쭉함.
3. **3회차** — 우니: 더 주황(236,116,20 / 246,146,32), 바깥 덩어리를 짧고 낮게, 가운데 둘을 높게 → 시트처럼 볼록한 주황 더미 + 잎 + 높은 김 띠. 장어: 더 진하게 했지만 렌더러 Glass가 붉게 보이고 윗면이 밋밋함.
4. **4회차** — 장어: 호박빛 판 + 진한 타레 등성이 두 톤 시도 → 판이 주황이 되어 연어와 더 헷갈리고 등성이 끝이 또 귀처럼 보임. 되돌림.
5. **5회차** — 장어: 한 톤 진갈색(100,58,28) Glass 판 → 시트의 "진갈색 윤기 + 김 띠 + 세로 김"으로 읽힘. 문어 가장자리를 마젠타 → 적갈 보라(150,40,62). 유부: 입 위 흰 네모 발견 → 입 덮개 색 수정. 최종(high) 렌더와 40종 줄 세우기에서 9종이 서로 구분됨: 장어(진갈 판 + 띠) ↔ 연어(주황 돔), 성게(높은 김 그릇 + 큰 주황 덩어리) ↔ 연어알(작은 빨간 알 + 오이), 문어(흰 돔 + 적갈 테 + 빨판) ↔ 새우(흰 + 주황 줄 + 꼬리), 유부는 몸 전체 갈색. 휴대폰 뒤 카메라(480×270)에서도 색 덩어리로 구분돼요.
- 남은 약점: 장어 판 윗면이 평평해서 시트의 "물결 살 결"은 없어요(파츠 상한). 유부 맨 위 접힌 자락이 판자처럼 보일 수 있어요(유부 시트가 없어 첫 해석 그대로).
