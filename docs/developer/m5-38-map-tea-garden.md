### 설계 요약
- **좌표**: 정원 중심 = origin, 5단 윗면 = y 0, 각도 a는 x = r·cos a, z = r·sin a. 단 k(1 = 가장 안·높음) 윗면 6/4.5/3/1.5/0.
- **조각**: 단마다 30° 부채꼴 12개를 상자 하나로 근사 — 폭 = 바깥 현(2·outer·sin15°), 안·바깥 면 = inner·cos15°·outer·cos15°. 이웃 단의 맞닿는 면이 같은 현이라 단 사이 틈 0, 조각 경계선 바깥 끝까지 상자가 덮어 조각 사이 틈 0(같은 단 조각끼리는 안쪽에서 겹치지만 같은 높이·같은 색이라 깜빡임 없음). 밑면은 모두 `BASE_Y −6`(바깥 단이 무너지면 흙·돌 옆면이 보임). 조각 = Model(태그 `TeaTerrace`, 속성 `Ring`·`Index`) 안에 `Slab`(Grass 재질 + Plastic 물성) + `WarnEdge`·`WarnBorder`(평소 투명) + `Decor`(차나무 이랑·흙 띠·쟁반 벽 — 조각과 같이 무너짐).
- **찻사발 심** `BowlCore`: 보이지 않는 원기둥 반지름 7, −6 ~ 20, 태그 `TeaBowlCore`. 연장전 +collapseDuration에 `CanCollide = false`.
- **찻잔** `Cup1~3`(태그 `TeaRollingCup`): build에서 미리 3개(본체 원기둥 지름 6·폭 4 + `CupGlow` + 무늬 장식), 전부 충돌·터치·쿼리 없음. `Cup1`만 소개 카메라용으로 1단에 세워 두고 `start`가 숨겨요. 서버 Heartbeat가 `PivotTo`(구르는 회전 = 이동 거리 / 반지름).
- **상태**: `roundStates[ctx]`(IkuraBombs·SkewerShowdown 방식) — 단 상태(phase·dropAt·owner), 찻잔 상태(status·motion·move·nextDecision), 쿨다운. 모듈 수준 가변 상태는 이 표 하나.
- **일정**: 본 경기 5·4·3단은 `start`에서 `task.delay`(경고 = 무너짐 −3초) 6개. 경고 깜빡임·무너짐 애니메이션은 Heartbeat 연결(전부 `ctx.cleanup`). `task.wait` 없음.
- **찻잔 판단**(Heartbeat): 새 찻잔은 `cupWave(t + 1.5)`가 늘면 하나씩 경고(찻사발 아래 `BowlGlow` 깜빡임 + `TeaCupRoll`) 뒤 찻사발에서 굴러 나와 1단으로. 찻잔마다 6초마다 `shouldMoveCup`(위험·겹침이면 꼭, 아니면 50%) → `pickCupRing`(이웃 단) → 1.2초 경고(`CupGlow` + 점선 호 6조각 + `TeaCupRoll`) → 0.5초 동안 반지름·높이 보간(+튀어 오름 2.2). 지금 단이 4초 안에 무너지면 그 틱에 바로 판단.
- **맞음**: 발 높이 = 루트 로컬 y − (HipHeight + 루트 높이/2) (AppearanceService와 같은 식). `cupHit` → `cupKnockback`(진행 26 + 바깥 12 + 위 18) → LinearVelocity 0.12초 + PlatformStand 0.8초 + `MoveExempt.mark(char, 1.5)`, 같은 사람 1초 쿨다운.
- **연장전**: 경고 전(`Solid`) 단만 `overtimeCollapse`로 다시 잡고(owner = overtime → 본 경기 delay가 뒤늦게 와도 무시), +collapseDuration에 남은 단 전부·심 충돌 끄기·찻잔 멈춤/숨김. start가 실패했어도(상태 없음) 모델에서 상태를 만들어 무너뜨려요.
