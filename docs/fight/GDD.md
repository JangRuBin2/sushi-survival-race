## 1. 개요

| 항목 | 내용 |
|---|---|
| 플랫폼 | Roblox (PC / 모바일 / 콘솔) — 스시런과 같음 |
| 장르 | 파티 격투, 장외 난투 (스매시브라더스류) |
| 인원 | MVP 4~8명 개인전 |
| 한 판 길이 | 약 3분 (시간 제한 150초 + 서든데스) |
| 캐릭터 | 스시런 스킨 41종 그대로 (겉모습만) |
| 한 줄 소개 | 초밥끼리 김 싸대기·박치기로 간장을 먹여서 접시 밖으로 날려 버린다 |

### 1.1 차별점
- **HP 대신 간장 게이지(%)**: 맞을수록 초밥이 간장에 절여져 색이 진해지고, 진할수록 멀리 날아가요. 위험한 사람이 화면에서 바로 보여요.
- **장외 KO = 젓가락 연출**: 접시 밖으로 떨어지면 손님 젓가락이 집어서 먹어요. 스시런의 핵심 웃음(먹히는 연출)을 그대로 가져와요.
- **스킨은 겉모습만**: 능력 차이는 맵에서 줍는 재료 토핑으로만 줘요. 로벅스 스킨이 페이투윈이 되지 않아요.

## 2. 핵심 루프
```
로비(스시런과 공유) → 파이트 방 입장 → 아레나 배정·소개(3초)
  → 난투(150초): 때리기·박치기·잡고 던지기 + 아이템 → 장외면 목숨 -1, 2초 뒤 부활
  → 마지막 1명 남으면 우승 / 시간 끝이면 판정·서든데스
  → 결과·보상(밥알 코인, 🎫 뽑기권) → 로비
```

## 3. 간장 게이지와 넉백

### 3.1 간장 게이지
- 0%에서 시작, 맞으면 기술마다 정해진 만큼 올라가요. 상한 **300%**.
- 장외로 목숨을 잃고 부활하면 **0%**로 돌아가요.
- 화면 표시: 머리 위 % 숫자 + 초밥 색 진하기(0% 원래 색 → 150%부터 최대로 진함).

### 3.2 넉백
- 넉백 속도 = `기술 기본값 + 맞은 뒤 게이지 × 기술 배율` (studs/초), 상한 **220**.
- 방향은 때린 사람 → 맞은 사람 수평 방향 + 기술마다 정한 위로 띄우는 비율.
- 경직(아무것도 못 하는 시간) = `넉백 속도 × 0.004`초, 최소 0.1초 · 최대 1.2초.
- 같은 사람에게 연속으로 맞으면 0.4초 동안은 같은 기술로 다시 안 맞아요(무한 연타 방지).

### 3.3 장외 KO
- 아레나 바닥보다 **25 studs 아래**로 떨어지거나, 아레나 중심에서 수평으로 **아레나 반지름 + 60 studs** 밖으로 나가면 장외예요.
- 장외 직전 **5초 안**에 마지막으로 때린 사람이 KO 점수를 받아요. 혼자 떨어지면(자폭) 점수 없음.
- 부활: 2초 뒤 아레나 위 부활 지점에서, **2초 무적**(맞아도 게이지·넉백 없음, 깜빡임 표시).

## 4. 조작 (버튼 4개)

| 버튼 | PC | 게임패드 | 모바일 | 동작 |
|---|---|---|---|---|
| 점프 | Space | A | 점프 | 2단 점프 |
| 다이브 → **박치기** | Shift / E | X | 다이브 | 앞으로 몸통 박치기. 맞으면 큰 넉백, 빗나가면 착지 후 엎드림(빈틈) |
| 잡기 → **잡고 던지기** | 마우스 왼쪽(누름) | R2 | 잡기 | 잡고 있다가 떼면 바라보는 방향으로 던짐. 최대 1.5초 잡기 |
| **때리기** (신규) | 마우스 오른쪽 / F | B | 때리기 | 김 싸대기. 약하지만 빠름(0.35초 간격) |

- 모바일 버튼은 스시런 3개 → **4개가 상한**. 버튼 위치 편집(m5-41)을 그대로 써요.
- 다이브·잡기의 기존 수치(스시런 `Config.Dive`·`Config.Grab`)는 이동감 기준으로 재사용하고, 판정은 파이트 전용 로직에서 해요.

| 기술 | 게이지 +% | 기본 넉백 | 배율 | 위로 비율 | 재사용 대기 |
|---|---|---|---|---|---|
| 때리기 | 4 | 10 | 0.12 | 0.25 | 0.35초 |

## 5. 아이템 (재료 토핑)
맵 곳곳에 8~12초마다 1개씩 생겨요(동시 최대 3개). 닿으면 자동으로 먹어요.

| 아이템 | 효과 | 수치 (기본값) |
|---|---|---|
| 와사비 | 매워서 불꽃 대시. 닿은 상대를 크게 넉백 | 3초, 게이지 +15, 기본 40 · 배율 0.45 |
| 간장병 | 발밑에 간장 웅덩이. 밟은 상대가 미끄러지고 게이지가 오름 | 웅덩이 6초, 초당 +2% |
| 연어알 | 던지는 폭탄. 연어알 폭탄 접시 맵 코드 재활용 | 반경 8, 게이지 +14, 기본 35 · 배율 0.40 |
| 초생강 | 입가심. 게이지 회복 | -30% |
| 젓가락 소환 (희귀, 5%) | 게이지가 가장 높은 상대(나 제외)를 손님이 집어 감 = 즉시 장외 | 대상 게이지 100% 이상일 때만 |

## 6. 아레나 (스시런 맵 재활용)
MVP는 스시런 **결승 맵 3개**를 아레나로 써요. 맵 모듈의 `build`(판정 지오메트리 + 장식)를 그대로 쓰고, 탈락 판정은 파이트 규칙(3.3)으로 바꿔요.

| 스시런 맵 | 파이트에서 | 단계 |
|---|---|---|
| `skewer-showdown` 회전 꼬치 쇼다운 | 기본 아레나 | MVP |
| `ikura-bombs` 연어알 폭탄 접시 | 기본 아레나, 연어알이 스테이지 기믹 | MVP |
| `tea-garden` 찻잎 정원 | 기본 아레나 | MVP |
| `tug-of-war-platform`·`claw-machine-prize`·`onsen-claw` | 아레나 | 2차 |
| `chef-board` 셰프의 도마 | 칼이 내려오면 게이지 +크게 | 2차 |
| `hot-plate`·`tempura-pot` | 달궈진 구간에 서 있으면 게이지가 오름 | 2차 |
| `rotating-belt` | 바닥이 계속 돌아가서 가장자리 싸움 | 2차 |
| `cat-cafe-shelves` | 고양이 앞발이 랜덤으로 쳐냄 | 2차 |
| `lazy-susan` 중식당 회전 원판 | 대인원(9명 이상) 난투 | 3차 |

- 결승 맵의 `overtime` 훅(바닥 붕괴)은 **서든데스**에 그대로 써요(7.2).

## 7. 모드

### 7.1 오마카세 난투 (MVP)
- 4~8인 개인전, 목숨 **3개**, 시간 **150초**.
- 목숨이 0이 되면 탈락 → 관전(스시런 관전 재사용).
- 마지막 1명이 남으면 즉시 우승.

### 7.2 시간이 끝나면
1. 남은 목숨이 가장 많은 사람이 1명이면 그 사람이 우승.
2. 여럿이면 그 사람들만 **서든데스**: 목숨 1개, 게이지 **150%**로 시작하고 아레나 `overtime` 붕괴(20초). 먼저 떨어진 사람이 아래. 안전 상한 30초에 가장 높이 있는 사람 우승.
3. 2등 아래 순위: 살아 있는 사람은 목숨 많은 순 → 게이지 낮은 순 → KO 많은 순, 탈락한 사람은 늦게 탈락한 순.

### 7.3 다음 모드 (2차 이후)
- **간장 vs 와사비**: 4v4 팀전, 접시 점령전
- **셰프의 특선**: 비대칭. 1명이 거대 셰프 손, 나머지는 초밥
- **손님 주문 이벤트**: 매치 중 "3번 테이블 손님 주문!" → 랜덤 1명이 10초 동안 젓가락 타겟(게이지 +50% 상태로 표시)

## 8. 보상 · 경제 (스시런과 공유)
- 같은 유니버스라 **프로필(밥알 코인·스킨·칭호·🎫)을 그대로 공유**해요(결정 필요 Q1).
- 기본값: 판 참가 +10, KO 1번당 +5(최대 +25), 우승 +60 + 🎫 1장. 하루 첫 판 보너스는 스시런과 합쳐 하루 1번.
- 스킨 규칙·뽑기 규칙·결제는 스시런 GDD 9절을 그대로 따라요. **능력치 판매 없음, 유료 뽑기 없음.**

## 9. 기술 설계 요약
- 스시런 저장소 안에 파이트 코드를 둬요: 순수 로직 `src/shared/fight/`, 서버 `src/server/fight/`, 클라이언트 `src/client/fight/` (F1-02부터).
- 판정은 전부 서버(타격·넉백·장외·KO 점수·아이템). 클라이언트는 입력·연출만 — 스시런 원칙 그대로.
- 플레이스: `PlaceRole`에 `"Fight"` 역할을 추가하는 방향(결정 필요 Q1). 공용 파일(`Config`·`Remotes`·`PlaceRole`·`init` 스크립트) 변경은 기반 스펙 하나(F1-02)가 맡아요.
- 넉백은 서버가 `AssemblyLinearVelocity`로 주고 `MoveExempt.mark`로 이동 감시 면제(스시런 규칙과 같음).
