# M3 플레이테스트 기록 (친구 테스트)

M3 완료 기준인 친구 테스트 결과를 모으는 곳이에요. 방법과 기본값 목록은 `docs/DEV-SETUP.md` 3-8 "N. 친구 테스트"에 있어요.

- 4명 이상, 3판 이상. `Config.DEBUG.forceMapPlan`은 nil 그대로.
- **판마다 아래 표에 한 줄**씩 추가해요. 칸이 모자라면 짧게 쓰고 자세한 건 표 아래 "메모"에.
- 맵 순서는 id 앞글자로 짧게 적어도 돼요: 벨트(`rotating-belt`), 늪(`soy-swamp`), 철판(`hot-plate`), 꼬치(`skewer-showdown`).
- 다 모이면 메인 세션에 알려 주세요. 기획 담당이 바꿀 수치·연출을 정리해 GDD v0.4·스펙에 넣고, 개발 담당이 `src/shared/Config.luau`를 고쳐요.
