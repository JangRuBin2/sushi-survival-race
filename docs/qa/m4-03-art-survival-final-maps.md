## 판정 회귀 점검 (최우선)
- **철판 타일**: 크기·위치·두께·CanCollide·태그·층 수·탈락 높이 그대로(`HotPlate.luau:87-110`). 달아오름 시간·색 단계 간격·`vanish` 그대로. 발밑 레이캐스트는 `FilterType = Include` + 이 방 타일 목록이라 장식(CanQuery 꺼짐)은 원래도 걸리지 않음(`:150-152`).
- **Neon 재질 전환과 물성 고정**: M2 타일은 `DiamondPlate` 기본 물성이었고, 이번에 `CustomPhysicalProperties = PhysicalProperties.new(DiamondPlate)`로 고정 → 차가운 상태의 마찰·밀도는 M2와 동일, Neon(기본 마찰 다름)으로 바뀐 뒤에도 같음. **타당**. 재질 전환은 색 단계가 바뀔 때만 한 번(`tile.Material ~= Neon` 확인) — 매 프레임 쓰기 없음.
- **HotPlateLogic 색 상수**: 사용처는 `HotPlate.luau`(초기 색)와 `heatVisual` 보간뿐. 판정에 쓰이지 않음. 기존 "달아오르는 동안 초록·파랑이 늘지 않음" 테스트 통과.
- **꼬치**: 크기·두께·CanCollide/CanTouch 끔·회전 속도(`Logic.speeds`)·`Logic.isHit`·넉백 수치·넉다운 시간 그대로. 색만 `PALETTE.Wood`. 음식 장식은 `Decor/<Skewer>Food` 폴더에 있고 매 Heartbeat `BulkMoveTo`로 따라감, 판정 루프와 무관.
- **기둥**: 크기·위치 그대로, 재질 Metal → SmoothPlastic(옻칠)이지만 `CustomPhysicalProperties = Metal`로 물성 유지. 타당.
- **무대 조각**: 띠 크기·위치 그대로, 색만 흰 도자기 + 바깥 줄 남색. 조각 장식(금 선·RimLip)은 조각 Model 자식이라 경고 깜빡임(빨강)·흔들림·들어 올림·`Destroy`를 조각과 같이 따름(`grabSlice`, `SkewerShowdown.luau:290-344`). 장식은 원래 CanCollide 꺼짐이라 집을 때 `CanCollide=false`로 바뀌어도 영향 없음.
- **셰프 손**: 일정(`Logic.grabTimes`)·내려오는 높이·시간 그대로. 손끝·소매 장식은 손 Model 안이라 `PivotTo`로 같이 움직임. 손끝이 집는 조각 윗면 아래 0.85까지 내려감(조각 두께 1.5 안) — 집는 모양이라 문제 아님(QA 테스트로 고정).
- **결승 규칙·낙하 높이**: `FALL_DEPTH = 20`, `ctx.eliminate` 경로 그대로. 무대 아래 셰프 상체 최고점 -39 < -20.
- **MoveExempt**: 꼬치 넉백에 `MoveExempt.mark(player.Character)` 추가(`SkewerShowdown.luau:441`). 셰프 손은 캐릭터 속도를 바꾸지 않음(바닥만 사라짐) → 표시 불필요. 철판은 서버가 속도를 바꾸는 곳 없음.
- **스폰 (코디네이터 추가 확인)**: 철판 24개 모두 맨 위층 타일 위, 가장 바깥 스폰이 가장자리에서 x 4.5 / z 6.75 studs 안쪽. 꼬치 24개 모두 반지름 14 원 위 → 무대 바깥 변(apothem 20.3)까지 6.3, 기둥(반지름 2.5)까지 11.5. 실제 띠(직사각형) 판정 바닥으로 중심과 몸통 둘레를 직접 확인. **문제 없음** (QA 테스트 3개로 고정).
