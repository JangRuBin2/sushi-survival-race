### [P3] B1 젤리 튕김 실제 정점이 스펙(약 13)의 두 배 가까이(약 24)
- 재현: C 구간 젤리 위에 서기. 서버가 `LinearVelocity`(위 72, `MaxForce` 무한)를 **0.15초 유지**한 뒤 풀어서, 유지하는 동안 72 × 0.15 ≈ 10.8 오르고 그다음 포물선으로 72² / (2 × 196.2) ≈ 13.2 더 올라요.
