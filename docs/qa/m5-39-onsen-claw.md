## 연장전 · 설 곳 0 (m5-18 B1 교훈)
- 훅(`OnsenClaw.luau:770-831`)에 `task.wait` 없음, 예약은 전부 `ctx.cleanup:add(task.delay(...))`. 모의 실행 두 개(기존 스펙 + QA 코루틴 스케줄러 — 훅 스레드에서 `task.wait`하면 에러가 나게 만듦)에서 훅이 시간을 쓰지 않음.
- +20초에 충돌 있는 것: **0**. 데크 조각은 `CanCollide/CanQuery/CanTouch = false`, 몸체(윗면 24)는 `CanCollide = false`. 탕 테두리 바위·울타리·간판·여관·마당 돌바닥(윗면 8)·섬 바위는 `MapKit.buildDecor`(충돌·쿼리·터치 없음), Studio 장식(`attachStudioArt`)도 같은 규칙. 고리·잔물결·거품 파츠는 `ghost`.
- **물에는 충돌·부력이 없음**: 물 표면·깊은 물빛은 `Part`(Glass/SmoothPlastic) + `ghost` — Terrain 물이 아니라 수영·부력 없음. 판정은 숫자 `waterHeight`(발 < 물 − 0.5)라 물 위에서 버틸 방법 없음.
- 연장전 전에는 4단 4개 + 몸체가 89.9초까지 남음(QA 테스트) — 시간 전에 설 곳이 바닥나지 않음(m5-19 B2).

## 버그
### [P2-1] 고리를 향해 안쪽으로 걸어가면 약 36% 확률로 충격파를 그냥 통과한다
- 재현 (순수 계산, 60Hz 틱): 3단 거리 30에 서서 쿵이 나면 가운데 쪽으로 걷는다(WalkSpeed 16). 시작 위치를 0.67 안에서 200가지로 바꿔 `Logic.waveHit`으로 계산하면 **72/200 놓침**(속도 8이면 36/200, 20이면 94/200, 서 있으면 0/200).
- 기대: 땅에 서 있는 사람은 고리가 지나가면(사람이 고리를 가로질러도) 맞는다. 피하는 방법은 점프뿐(스펙 "점프 중이면 안 맞는다", GDD "충격파는 점프로 넘고").
- 실제: 판정이 "이번 틱에 고리 앞면이 지나간 구간 (prevRadius, radius]에 지금 거리가 들어 있나"만 본다. 사람이 안쪽으로 움직이면 한 틱 사이에 사람 거리가 이전 고리 반지름보다 안쪽으로 넘어가 구간을 건너뛴다(상대 속도 40 studs/s, 틱당 0.67 중 0.27을 사람이 움직임). 서버 프레임이 늘어지면 더 자주 샌다. "고리 쪽으로 달려들기"가 점프 대신 쓸 수 있는 회피법이 된다.
- 위치: `src/shared/maps/OnsenClaw.luau:711-715`(현재 거리만 사용), `src/shared/maps/OnsenClawLogic.luau:182-190`(`waveHit`)
- 제안: 고리마다 사람별 직전 거리를 기억하고 "직전엔 고리 바깥(prevDist > prevRadius), 지금은 안쪽(dist ≤ radius)"이면 맞음으로(상대 위치 부호가 바뀌는 순간). `waveHit`에 `prevDist` 인자를 더하거나 별도 함수 + 테스트.

### [P3-1] 기계 앞 조작판이 4단에서 뛰어 오를 수 있는 선반처럼 보이지만 충돌이 없다
- 재현: 4단(윗면 6) 남쪽 안쪽 가장자리에서 기계 앞면 조작판(쐐기, 윗면 약 9.9)으로 점프한다.
- 기대: 보이는 발판은 서거나, 서지 못할 모양이어야 한다(아트 가이드 가독성).
- 실제: 조작판·버튼·문은 충돌 몸체(±6.3) 밖으로 최대 0.9 튀어나온 장식이라 통과해서 몸체와 4단 사이 물(폭 약 3.7)로 떨어진다. 깊이가 0.9뿐인 기울어진 판이라 실제로 노리는 사람은 드물고, 떨어지는 곳도 원래 낙하 구역이라 규칙 문제는 아님.
- 위치: `src/shared/maps/OnsenClawArt.luau:371-396` (`ControlPanel`·`PushButton`·`Joystick`)
- 제안(선택): 조작판을 몸체 면 안쪽으로 넣거나 더 가파르게. Studio 체크리스트 4에서 같이 본다.

### [P3-2] 발 높이 상수 3이 이 게임 캐릭터의 루트 높이(2.25)와 다르다 (확인 필요)
- 내용: `Layout.FOOT_OFFSET = 3`인데 캐릭터 히트박스·발바닥 기준은 `SushiBody.GROUND_OFFSET = 2.25`. 그러면 계산한 발이 실제 발보다 0.75 낮다. 영향: 고리 피하기는 실제 발이 윗면 + 1.95를 넘어야 함(점프 높이 6.4에서 체공 약 0.43초라 여전히 충분), 물 탈락은 실제 발 < 물 + 0.25. 데크에 서 있으면 안전한 건 그대로(가라앉기 전 물 ≤ 윗면 − 2). `TempuraPot`도 같은 3을 쓰는 기존 관례라 규칙 문제는 아니고, Studio에서 체감이 이상하면 이 값을 본다.
- 위치: `src/shared/maps/OnsenClawLayout.luau:78`

(참고, 버그 아님) 연장전이 쿵 경고 1.5초 도중에 시작되면 경고를 취소하고 연장전 일정(시작 + 3초)으로 다시 잡아 집게가 한 번 올라갔다 다시 내려온다. 보통 90초에는 다음 경고가 90.5초부터라 안 생기고 디버그 `overtimeAt`에서만 가끔.
