## 목표
결승 맵. 가게 문까지 이어진 좁은 꼬치 다리와 회전 접시를 건너며, 떨어지는 장국 그릇과 막판의 셰프 손을 피해 가장 먼저 문을 통과한 1명이 우승한다. 떨어지면 재시작 없이 탈락.

## 범위
- 포함 (이 worktree가 고치는 파일: `src/shared/maps/SkewerBridge.luau`, 새 파일 `src/shared/maps/SkewerBridge*.luau`, 새 파일 `tests/map-skewer-bridge.spec.luau`(선택))
  - **코스 구성** (origin에서 로컬 -Z, 전체 길이 160~220 studs, 공중에 떠 있음):
    1. 출발 발판 — `Spawns` 24개 (결승은 보통 2~5명이지만 계약대로 24개)
    2. **꼬치 다리 1** — 폭 3~4 studs의 긴 원기둥/각기둥 다리, 난간 없음. 갈림길로 2갈래 이상(한 줄로만 막히지 않게).
    3. **회전 접시 구간** — 지름 12~16 studs 원판 3~4개가 수평으로 돈다(초기 30°/s, 원판마다 방향 다름). 접시 사이 간격은 점프로 건널 수 있는 거리. 플레이어가 접시 위에 서 있을 수 있어야 한다(물리로 같이 돌거나 미끄러지는 건 괜찮다, 통과해서 떨어지면 안 된다).
    4. **꼬치 다리 2 + 장국 그릇** — 다리 위로 장국 그릇이 떨어진다: 떨어질 자리에 빨간 원 경고 1초 → 그릇이 위에서 떨어짐 → 맞은 레이서는 옆으로 밀려나고(넉백) 1초 넘어진다(`PlatformStand`). 그릇은 떨어진 뒤 사라진다.
    5. **셰프의 손** — 마지막 30~40 studs. 거대한 손(회색 박스)이 3~5초마다 코스를 가로질러 쓸고 지나간다(쓸기 직전 0.5~1초 손이 들리는 예고 동작). 닿은 레이서는 진행 방향 옆으로 크게 밀린다 — 다리 밖으로 떨어질 수 있다.
    6. **가게 문** — 문틀 + 문 안쪽의 `FinishLine`(CanCollide false).
  - **판정 (서버)**:
    - 문(결승선) 통과 → `ctx.pass(player)`. 마지막 라운드라 첫 통과자는 `RoundService`가 우승 처리한다. 점프해서 넘어도 통과로 판정되게 한다 (M1 B2 수정 방식을 따른다). 문 뒤에 바닥과 벽이 있어 넘어가도 떨어지지 않는다.
    - 장애물 태그 규칙은 m2-02 결정 기록의 B10 결정을 따른다.
    - HumanoidRootPart가 코스 최저 높이보다 30 studs 아래로 내려가면 `ctx.eliminate(player)` (재시작 없음).
    - 시간 종료 시 "가장 멀리 간 사람 우승"은 `RoundService`가 로컬 -Z 축으로 잰다 → **코스는 반드시 -Z로 꾸준히 전진**해야 한다(갈림길·접시도 뒤로 돌아가지 않게).
  - 모든 연결·스레드·생성한 그릇은 `ctx.cleanup`에, 상태는 `ctx`/지역 변수에.
  - 튜닝 초기값(지역 상수): 그릇 간격 2~3초, 손 주기 4초, 넉백 속도 40~60 studs/s.
- 제외:
  - "셰프가 잡아감" 탈락 연출, 부두·바다 우승 연출 (M3 / GDD §7, §8)
  - 결승에서 혼자 남았을 때·모두 떨어졌을 때 우승 규칙 → `RoundService` 규칙이라 **m2-05** (사용자 결정 대기 Q2)
