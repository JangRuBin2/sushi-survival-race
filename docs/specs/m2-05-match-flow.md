## 목표
4종 맵으로 3~4라운드 한 판이 끝까지 공정하게 돈다: 모두 같은 순간에 출발하고, Survival·Final도 시간 종료나 낙하 때 결과가 분명하며, 우승 때 전체 순위가 나온다. 관전 UI(m2-06)가 쓸 생존자 정보를 서버가 방송한다.

## 범위
- 포함:
  1. **출발 공정성**: 맵 짓기와 플레이어 배치를 `RoundIntro`(3초) 동안 끝내고, 그동안 생존자는 스폰 위에서 **움직일 수도 점프할 수도 없다**. `RoundActive` 방송과 동시에 이동 잠금을 풀고 맵 `start(ctx)`를 부른다. (지금은 `RoundActive` 뒤에 맵을 짓고 배치해서 출발 시각이 사람마다 다르다.)
  2. **라운드 중 캐릭터 사망/리셋 = 탈락**: `RoundIntro`~`RoundActive` 사이에 아직 결판나지 않은 레이서의 캐릭터가 죽거나 사라지거나 새로 생기면 그 레이서는 즉시 탈락한다. (지금은 Survival에서 리셋해 로비로 가면 떨어질 일이 없어 끝까지 "생존"한다.) 라운드 사이(`RoundResults`) 리셋은 탈락이 아니다.
  3. **Survival 시간 종료 규칙** — Q1 결정대로 구현한다.
  4. **결승에서 혼자 남았을 때 / 모두 떨어졌을 때** — Q2 결정대로 구현한다.
  5. **Race 통과자 처리** — Q4 결정대로 구현한다. B1 수정이 라운드 종료 뒤 생존자를 옮겨 두는 안전한 장소를 이미 만들었다면 그 장소를 재사용한다.
  6. **매치 뒤 자동 시작** — Q5 결정대로 (`RoomService`).
  7. **생존자·순위 방송** (m2-01이 만든 `Types` 필드 채우기):
     - 모든 `MatchPhase` 방송에 `aliveUserIds` (이 매치에서 아직 탈락하지 않은 사람).
     - 모든 `RoundProgress` 방송에 `racerUserIds` (이번 라운드에서 아직 통과/탈락하지 않은 사람).
     - `Victory`에 `standings`: 이 매치를 시작한 **모든** 플레이어(중간에 나간 사람 포함, 이름은 매치 시작 때 저장)를 1등부터. 등수는 `PlayerResult`로 보낸 등수와 같다.
  8. **순수 로직 분리** `src/shared/RoundLogic.luau` (Roblox API 없음): 라운드 종료 판정과 종료 시 통과/탈락 나누기, 최종 순위표 만들기. `RoundService`는 이 결과대로 `EliminationService`를 부른다.
- 제외:
  - M1 소급 QA 버그 B1~B9 수정 (main에서 따로 진행 중 — 다시 고치지 않는다. 단, 이 스펙 작업 중 같은 버그가 재발하면 QA 리포트에 적는다)
  - 플라이스루 카메라·탈락/우승 연출 (M3), 보상 정산·코인 (M4)
  - 관전 카메라와 순위 화면 (m2-06)
  - 맵 내부 장애물 (m2-02~04)

- [ ] AC3: Survival, 목표 3, 남은 인원이 3이 되는 순간 → "종료", 남은 3명 전원 통과.

- [ ] AC5: 결승 — Q2 결정을 옮긴 케이스 (예: 추천안이면 "결승 3명 중 2명 낙하 → 남은 1명 즉시 우승", "남은 2명이 같은 판정 틱에 낙하 → 더 멀리 간 사람 우승, 다른 사람 2등").
- [ ] AC6: 결승에서 누군가 문을 통과하면 우승 1명, 나머지는 진행도 순으로 2등, 3등…
