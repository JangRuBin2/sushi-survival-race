## 목표
업소용 개수대 속, 거품 낀 설거지물 위에 떠 있는 **빙글빙글 도는 접시**를 건너뛰고, 칸막이 선반을 가로질러 왕복하는 **거대한 수세미**를 피해, 건조대의 반짝이는 깨끗한 접시(결승)까지 달린다. 접시는 원판마다 도는 방향이 반대라 서 있으면 옆으로 쓸려 물에 빠진다 — "도는 원판 사이를 리듬 있게 건너기"가 핵심 손맛이다.

### 회전 접시 (서버, `RotatingBelt` 밀기와 같은 방식 — 연속 밀기)
- 접시 파츠는 **움직이지 않는다**(Anchored 고정 — 옆으로 움직이는 발판은 캐릭터가 같이 안 움직여 미끄러지는 문제, m4-04 결정 기록). 대신 서버가 접시 위 사람을 접선 방향으로 민다. 도는 느낌은 접시 테두리 장식(충돌 없음, 판정 파츠와 분리된 고정 장식)의 `Spin` `anim`으로 보여 준다(주기 5초 = 시트 "약 5초").
- 방향: (행 + 줄) 짝수면 시계 방향, 홀수면 반시계(위에서 볼 때) — 이웃 원판끼리 항상 반대.
- 접시 위(윗면 + 5 안, 중심에서 반지름 R 안)에 있는 레이서: 목표 수평 속도 = 접선 방향 `min(ω·r, cap)` + 가장자리(r > 0.7R) 바깥쪽 `2.5`. B 접시: R 10, ω = 2π / 5, cap 8. E 큰 접시: R 13, ω = 2π / 4, cap 10. 지금 속도를 그 목표 쪽으로 가속(회전 벨트와 같은 가속 상수). 걷기 16이 밀기 8보다 빨라서 거슬러 갈 수 있다. 가만히 서 있으면 몇 초 안에 가장자리로 쓸려 물에 떨어진다.
- `Logic.plateDirection(row, lane) -> 1 | -1`, `Logic.platePush(dx, dz, dir) -> (vx, vz)?`(접시 중심 기준 상대 위치, 접시 밖이면 nil).
- 연속 밀기라 **`MoveExempt.mark`를 달지 않는다**(CLAUDE.md "이동 감시 면제"). 최대 밀기 8.5 + 걷기 16 = 24.5 < 이동 감시 상한 80.

### 수세미 (서버, 태그 `SinkSponge`)
- 크기 x 9 × y 6 × z 7(노랑 스펀지 + 연두 수세미 면), **CanCollide/CanQuery/CanTouch = false**(판정은 서버가 숫자로 — 물리 충돌로 이상하게 끼지 않게). 서버가 매 Heartbeat `CFrame`으로 옮긴다.
- C: 위치 z −127, −153, −179. x 중심이 −12 ↔ +12를 왕복: **주기 8초**(시트 "약 8초") = +12에서 1.5초 멈춤 → 2.5초 동안 −12로 → 1.5초 멈춤 → 2.5초 동안 +12로. 수세미 3개 위상 0 / 2.7 / 5.3초.
- E: 선반 다리(폭 10) 수세미 1개 z −305, 같은 8초 주기, 왕복 x −11 ↔ +11.
- F: 복도 폭 16, 큰 수세미(x 11) 2개 z −352·−375, 왕복 x −14 ↔ +14(끝에서 안쪽 면 |x| 8.5 → 복도가 빔), 같은 8초 주기, 위상 0 / 4초(서로 반대 끝).
  - 양 끝(|x| = 12)에서는 수세미 안쪽 면이 |x| 7.5라 선반(|x| ≤ 6)이 **완전히 빈다** → 멈춤 1.5초가 "지금 지나가!" 타이밍. 가운데 쯤에서도 반대쪽에 폭 7 이상 틈이 생겨 비켜 지나갈 수 있다.
